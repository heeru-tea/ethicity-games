# 인권보장 피드백 수정본 v0.9

2026-11-15, 교사 피드백 PDF의 1~3쪽에 해당하는 인권보장 수정본입니다.
기존 `rights/`와 공공성 게임은 변경하지 않았습니다.

## 실행 및 편집

- 저장소 루트에서 HTTP 서버를 실행하고 `/rights-preview/`를 엽니다.
- 배포 시 `rights-preview/`와 `shared/`의 상대 위치를 유지합니다.
- 선택지·이야기: `scenario.json`
- 판단 분기: `source/outcomes.js`
- 화면과 동작: `source/game.js`, `source/style.css`, `source/template.html`
- 재생성: `python rights-preview/source/build.py`
- 분기 검사: `node rights-preview/tests/outcomes.cjs`

## 반영 사항

1. 사건별 두 질문의 9개 조합에 따라 결말과 배지가 바뀝니다. 제한 유지 시 보호 성공 배지를 주지 않습니다.
2. 보호적인 정답으로 고칠 때까지 막던 구조를 없앴습니다. 모든 판단 결과를 기록하고 다음 사건으로 진행할 수 있습니다.
3. 관련 자료와 판단을 비교하고 다시 판단할 수 있습니다. 앞선 사건과 최종 화면에서도 재검토할 수 있습니다.
4. 최종 정책만 바꿔도 앞선 미완료 사건이 자동 해결되지 않습니다. 사건 변경 시 기존 최종 결과를 무효화합니다.
5. 선택지 24개의 문구와 결과를 함께 정리했습니다. 대체 출입·교차 확인을 선택했는데 불이익 설명이 나오던 불일치를 고쳤습니다.
6. 조사 중에는 짧은 선택 결과와 접을 수 있는 자료를 제공하고, 학습 정리는 사건 마지막에 모았습니다.
7. NPC 뒤 초록 밑줄을 제거했습니다. 추천 경로와 명시적인 빠른 이동을 제공합니다. 탭·포털은 접근성을 위해 병행합니다.
8. 결과의 X·Esc·바깥 영역 닫기와 다음 버튼이 같은 사건 전환을 실행합니다. 도입을 닫아도 경로 안내에서 다시 열 수 있습니다.
9. 가속·감속·포털 전환 효과는 유지했습니다.
10. v0.9 전용 저장 키를 써서 기존 공개 게임의 진행·결과 기록을 덮어쓰지 않습니다.
11. 증거 파일을 지도와 같은 열에 배치해 긴 오른쪽 안내판 때문에 생기던 빈 공간을 없앴습니다. 안내판을 축소하고 배지는 각진 네모를 유지합니다.

## 결과 구분

- 새봄: 발표 제한 유지 / 근거 재검토 / 기회를 지키며 추가 확인 / 작성 근거 인정·기회 회복
- 온유: 대체 출입 없는 운영 유지 / 제한 판단 재검토 / 사람 확인으로 입장 / AI 점검 중 대체 출입
- 최종: 권리 보호 미완료 / 재검토가 남은 학교 / 권리를 지키는 학교

자료 자체는 플레이어가 원하는 답에 따라 바뀌지 않습니다. 자료를 모두 볼 수 있음을 안내하고, 사건 판단과 대응의 차이를 결과에 반영합니다.

## 확인

- 두 사건 18개 답 조합과 8개 최종 조합 검사
- 브라우저에서 두 사건 조사, 제한 유지 결과, X로 사건 2 도입 전환, 최종 미완료 결과, 두 사건 재판단 및 배지 갱신 확인
- 수정 레이아웃 브라우저 확인: 지도 아래 14px 간격으로 증거 파일 연결
