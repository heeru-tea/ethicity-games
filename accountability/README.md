# 책임성: 청소 로봇 사건 조사

초등 AI 윤리 책임성 게임입니다. 단서를 확인하고 판단 또는 판단 유보의 이유를 남긴 뒤, 선택한 인물에게 게임 속 편지를 보내 회복·예방 방법을 제안합니다. 단일 범인이나 동일한 책임 비율을 정답으로 요구하지 않습니다.

## 팀 통합 및 실행

진입 파일은 `accountability/index.html`, 동작 코드는 같은 폴더의 `accountability-revision.js`입니다. 저장소 루트의 `shared/ethicity-elementary-common-v1/` 공통팩이 필요합니다. HTML은 공통 `common.css`, `manifest.js`, `common.js`를 순서대로 참조합니다. 공통팩은 변경하거나 이 폴더에 복제하지 않습니다. 담당 브랜치에 업로드하는 것과 main 통합·사이트 배포는 별도입니다. 공통팩을 포함한 팀 사이트에서 HTTP(S)로 실행하고 상대 경로를 유지하세요.

## 활동 흐름

1. **사건 보기 → 단서 찾기 → 이야기 듣기 → 해결하기**(4단계 번호·이름 유지). 각 단계는 "궁금한 점을 골라요" 화면에서 시작합니다. 원인/책임과 도움/예방 세 관점 카드 또는 "내 질문 쓰기"로 직접 적을 수 있고, 고른 카드는 선택 표시(✓)로 남습니다. 질문을 한 번 정하면 같은 단계에서 다른 자료로 넘어갈 때는 질문 화면을 다시 묻지 않고 바로 "조사할 곳을 정해요" 화면으로 이동하며, "질문 고치기"를 눌렀을 때만 질문 카드로 돌아갑니다. 새 단계가 시작될 때는 다시 질문부터 고릅니다.
2. 실제 자료·답변을 열면 확인 상태를 표시합니다. 수첩 기록과 판단 근거 선택은 별도입니다. 민호·가영·회사의 진술은 "인물의 말 / 이 말에서 생각해 볼 점 / 이 말만으로 알 수 없는 점" 세 가지를 한 화면에 함께 보여주며, 쉬운 말과 원래 말을 번갈아 보여주는 토글은 쓰지 않습니다. 후속 질문은 8개이며 기존 열림 조건을 유지하고, 일부 질문은 "들은 말 / 받아들인 뜻 / 행동에 관한 진술"을 구분해 보여줍니다. 지도에서 조사 대상 이름표는 글자 길이에 맞춰 크기가 정해지며 화면 밖으로 잘리지 않습니다. 지도 화면과 자료 확인 정리 화면 모두에서 "조사 멈추고 판단하러 가기"를 눈에 띄는 주버튼으로 제공하며, 자료를 하나도 기록하지 않았을 때는 비활성 상태와 안내 문구를 보여줍니다.
3. 판단 화면의 근거 목록은 자료(인물)별 카드로 묶여 있으며, 각 카드는 이름·"판단 근거로 사용" 체크박스·확인된 내용·"이 자료만으로 알 수 없는 점"을 항상 펼쳐서 보여줍니다. 판단 방식은 드롭다운이 아니라 "근거를 바탕으로 판단 남기기"/"아직 판단하기 어려움" 두 버튼이며, 새로 판단할 때는 기본 선택이 없고 하나를 고르기 전에는 저장할 수 없습니다. 판단을 유보하면 더 필요한 자료를 남기는 입력이 바로 펼쳐집니다. 판단 한 문장은 선택 입력입니다. 3단계 내용을 4단계 초안으로 이어받아 다시 쓰지 않고 검토·수정할 수 있습니다. 다음 버튼은 스크롤 본문과 분리된 하단 영역에 있고 선택 활동은 접혀 있습니다.
4. 4단계에서는 민호·선생님·회사·가영 순으로 역할별 화면에서 도움·예방 행동을 고르고, 고른 행동마다 "어떤 자료를 보고 생각했는지" 근거를 선택해 연결할 수 있습니다(선택 사항). 확인 화면에서 고른 행동을 다시 본 뒤, 조사 결과 화면의 편지 작성 도구로 이동합니다. 받는 사람은 역할 설명이 붙은 카드(가영·민호·선생님·회사)로 고르며 기본 선택값은 없고, 수신자·짧은 글·확인한 근거를 모두 채워야 발송할 수 있습니다. 수신자 선택 바로 옆에 "한 사람에게 편지를 보내도 모든 책임이 그 사람에게 있다는 뜻은 아니에요"를 표시합니다. 발송 → 수신자별 반응 장면과 선택한 회복·예방 행동 → **Case solved** → 조사 기록 다시보기로 이어집니다.

수신자는 민호·가영·교사·회사 중 한 명입니다. 한 편지의 복수 수신자 순차 재생은 지원하지 않습니다. 다른 편지를 보낸 기록은 보존됩니다. 편지는 게임 안에서만 전달되며 자유문을 AI로 분석하거나 실제 외부로 발송하지 않습니다. Case solved는 조사와 제안의 완료를 뜻하며 실제 피해 복구 완료를 의미하지 않습니다.

## 언어·기록·접근성

한국어/영어 전환은 정적 UI와 대사에만 적용하며 학생이 쓴 원문은 번역하거나 덮어쓰지 않습니다. 같은 탭의 sessionStorage에 조사·판단·편지·언어 상태를 보관하며 기존 저장 형식과 호환합니다. 탭 종료 후의 영구 보존이나 교사 서버 수신을 제공하지 않습니다. 필요한 기록은 게임의 JSON 저장 기능으로 내려받으세요. 실제 개인정보를 입력하지 마세요.

빈 편지·미확인 근거·중복 발송을 방지합니다. 이전 단계의 늦은 중복 클릭은 다음 판단을 자동 저장하지 않습니다. 설명서 문장과 질문 관점 카드의 공통 장식 테두리만 로컬에서 제거하고 선택 강조·aria-pressed·키보드 포커스는 유지합니다.

공통 runtime과 `ethicity:ready`, `ethicity:progress`, `ethicity:complete`를 연결하며 이벤트에는 학생 자유문·번호·UID를 싣지 않습니다. 개인 기록은 저장소에 포함하지 않습니다.

## 검증 범위

자동 검사: 12개 fake-DOM 스크립트(조사·판단·편지·엔딩 흐름 회귀, 언어 전환 27개 화면, 아바타 선택, 설명서 안내 문구, 하단 행동 영역 구조, 자동 이동 거리, 후속 질문 역할 화면, 질문 카드·판단 버튼·자료 카드·주버튼·의문 재진입 방지 7건)가 실제 게임 이벤트 핸들러와 렌더 코드를 대상으로 통과했습니다. 테스트 하네스는 공개 게임 파일에 포함하지 않습니다.

실제 화면 검수: 로컬 허용목록 서버로 데스크톱(약 800×600)과 모바일(375×812 에뮬레이션) 양쪽에서, 한국어·영어 양쪽에서 캐릭터 선택부터 7개 자료 전체·판단 4회·역할별 계획·편지 작성·수신자 반응·Case solved·기록 다시보기까지 처음부터 끝까지 직접 클릭·타이핑으로 확인했습니다. 콘솔 에러는 없었습니다. 이 과정에서 수신자 반응 장면에 같은 인물 초상이 두 번 표시되는 문제를 발견해 수정했습니다(현재 버전에는 반영됨, 한 번만 표시).

남은 범위: 실기기 터치, 교실 다인 동시 접속, 초등학생 실제 이해도 관찰은 하지 않았습니다. 좁은 화면(375px)에서 상단 "조사수첩/도움/English" 메뉴 버튼이 글자 단위로 줄바꿈되는 현상을 확인했는데, 이는 공용 헤더 레이아웃(공통팩과 연결된 영역) 문제로 보여 이번 게임 파일 수정 범위에 포함하지 않았습니다. 팀 공통 검토가 필요합니다. 원격 업로드만으로 브라우저 E2E나 사이트 배포가 완료된 것은 아닙니다.

## 2026-11-06 변경 내역

**1차**: 질문과 조사 대상 선택을 순서대로 나누고, 후속 질문에 "들은 말/받아들인 뜻/행동에 관한 진술" 구분과 조사수첩 "확인된 사실/아직 확실하지 않은 내용/더 알아볼 내용" 3분류를 적용했습니다. BGM은 기본 켜짐이며 조사 시작 클릭 후 재생합니다. 저장된 소리 선택을 우선하고 OGG 우선/MP3 대체, 탭 숨김 일시정지를 사용합니다.

**2차(이번 반영)**: 실제 화면 캡처 기반 검토에서 나온 7가지를 반영했습니다 — 질문 관점 카드의 장식 테두리 제거와 선택 표시, 민호·가영·회사 진술 화면의 쉬운말/원래말 토글 제거(세 구분을 항상 함께 표시), 지도 목적지 이름표의 가변 폭 적용, 판단 방식의 드롭다운→두 버튼 전환(기본 선택 없음), 판단 근거의 자료별 카드화, "조사 멈추고 판단하러 가기" 주버튼 노출, 의문 재진입 방지(같은 단계에서는 반복하지 않음). 이어서 전체 플레이를 처음부터 끝까지 다시 렌더링해 수신자 반응 장면의 초상 중복 표시 문제를 추가로 찾아 고쳤습니다.

이번 자동 핸들러/DOM/기하 회귀 검사와 실제 브라우저 전체 플레이스루를 통과했습니다. 실제 교실·학생 반응·실기기 터치 검수는 이번에도 별도 확인이 필요합니다.

## 2026-11-06 재검증 수정
- 고른 의문을 같은 사건 전체에서 유지하고, '의문 바꾸기'를 누를 때만 다시 고르게 함.
- 기록 없이도 판단 화면을 열 수 있게 하고, 저장 조건만 분리함(근거 기반 판단은 기록·근거·이유, 판단 유보는 더 확인할 것).
- 질문 카드 사이 쉼표 표시 버그 수정, 지도 이름표를 화면 배율에 맞게 보정.
