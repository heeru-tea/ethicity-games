# 책임성: 청소 로봇 사건 조사

초등 AI 윤리 책임성 게임입니다. 단서를 확인하고 판단 또는 판단 유보의 이유를 남긴 뒤, 선택한 인물에게 게임 속 편지를 보내 회복·예방 방법을 제안합니다. 단일 범인이나 동일한 책임 비율을 정답으로 요구하지 않습니다.

## 팀 통합 및 실행

진입 파일은 `accountability/index.html`, 동작 코드는 같은 폴더의 `accountability-revision.js`입니다. 저장소 루트의 `shared/ethicity-elementary-common-v1/` 공통팩이 필요합니다. HTML은 공통 `common.css`, `manifest.js`, `common.js`를 순서대로 참조합니다. 공통팩은 변경하거나 이 폴더에 복제하지 않습니다. 담당 브랜치에 업로드하는 것과 main 통합·사이트 배포는 별도입니다. 공통팩을 포함한 팀 사이트에서 HTTP(S)로 실행하고 상대 경로를 유지하세요.

## 활동 흐름

1. 사건 보기 → 단서 찾기 → 이야기 듣기 → 해결하기.
2. 실제 자료·답변을 열면 확인 상태를 표시합니다. 수첩 기록과 판단 근거 선택은 별도입니다. 후속 질문은 8개이며 기존 열림 조건을 유지합니다.
3. 확인한 근거와 판단 이유를 저장합니다. 판단을 유보하면 더 필요한 자료를 남깁니다. 판단 한 문장은 선택 입력입니다. 3단계 내용을 4단계 초안으로 이어받아 다시 쓰지 않고 검토·수정할 수 있습니다. 다음 버튼은 스크롤 본문과 분리된 하단 영역에 있고 선택 활동은 접혀 있습니다.
4. 도움 계획과 조사 결과를 확인한 뒤 편지 작성 도구에서 수신자·짧은 글·확인한 근거를 선택합니다. 발송 → 수신자별 장면과 선택한 회복·예방 행동 → **Case solved** → 조사 기록 다시보기로 이어집니다.

수신자는 민호·가영·교사·회사 중 한 명입니다. 한 편지의 복수 수신자 순차 재생은 지원하지 않습니다. 다른 편지를 보낸 기록은 보존됩니다. 편지는 게임 안에서만 전달되며 자유문을 AI로 분석하거나 실제 외부로 발송하지 않습니다. Case solved는 조사와 제안의 완료를 뜻하며 실제 피해 복구 완료를 의미하지 않습니다.

## 언어·기록·접근성

한국어/영어 전환은 정적 UI와 대사에만 적용하며 학생이 쓴 원문은 번역하거나 덮어쓰지 않습니다. 같은 탭의 sessionStorage에 조사·판단·편지·언어 상태를 보관하며 기존 저장 형식과 호환합니다. 탭 종료 후의 영구 보존이나 교사 서버 수신을 제공하지 않습니다. 필요한 기록은 게임의 JSON 저장 기능으로 내려받으세요. 실제 개인정보를 입력하지 마세요.

빈 편지·미확인 근거·중복 발송을 방지합니다. 이전 단계의 늦은 중복 클릭은 다음 판단을 자동 저장하지 않습니다. 설명서 문장의 공통 장식 테두리만 로컬에서 제거하고 선택 강조·aria-pressed·키보드 포커스는 유지합니다.

공통 runtime과 `ethicity:ready`, `ethicity:progress`, `ethicity:complete`를 연결하며 이벤트에는 학생 자유문·번호·UID를 싣지 않습니다. 개인 기록은 저장소에 포함하지 않습니다.

실제 브라우저 작은 화면의 잘림·픽셀 검수는 도구 초기화 제한으로 미완료입니다. 원격 업로드만으로 브라우저 E2E나 사이트 배포가 완료된 것은 아닙니다.
