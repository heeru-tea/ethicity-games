# 신뢰성 · 냠냠봇을 믿어도 될까?

`data/data_v5`는 기존 개인 탐험에 실제 Firebase 수업 모드를 더한 공개 버전입니다. 이전 버전은 그대로 보존합니다.

- [게임 시작](https://ethicity-nyamnyam-v2.hollowcorn.chatgpt.site/data/data_v5/)
- [교사 컨트롤 타워](https://ethicity-nyamnyam-v2.hollowcorn.chatgpt.site/data/data_v5/?mode=teacher)
- [혼자 하기](https://ethicity-nyamnyam-v2.hollowcorn.chatgpt.site/data/data_v5/?mode=solo)
- [윤리시티 게임 허브](https://ethicity-game-hub.hollowcorn.chatgpt.site/)

PC·태블릿·휴대폰에서 위 공개 주소로 접속합니다. 수업 참여 링크와 QR 코드는 교사가 수업을 만든 뒤 공유합니다.

## 유지한 내용

공통 팩과 공식 캐릭터, 바깥 배경색, 큰 장면과 하단 말풍선, 6개 이야기, 개인 선택에 따른 급식안, 선생님의 안전 확인, 평가 규칙, 타이핑·음악 설정, 학습 정리와 PNG 리포트를 유지합니다. `scenario.js`, `story.js`, `report.js`는 v4와 같습니다.

## 사용 방법

1. 교사 화면에서 **새 수업 만들기**를 누릅니다.
2. 학생은 수업 코드 또는 참여 링크로 들어와 닉네임과 A/B 탐험가를 고르고 **수업 참여하기**를 누릅니다. 실명 대신 한글·영문·숫자 1~12자의 별명을 사용하며, 계정 가입은 필요하지 않습니다. 이 준비 화면에서 **미리보기로 시작**도 선택할 수 있습니다.
3. 교사는 **첫 이야기 열기**부터 이야기 6개를 차례로 엽니다. 안내를 읽거나 이전 이야기를 진행하던 학생도 교사가 연 이야기로 즉시 함께 이동합니다.
4. 학생은 같은 이야기 안에서 자신의 선택을 합니다. 먼저 끝내면 대기하고, 교사가 **다음 이야기 열기**를 누를 때 이동합니다. 이미 한 선택은 보존하며, 하지 않은 선택이나 이야기 완료 기록을 임의로 채우지 않습니다.
5. **잠시 멈추기 / 계속 진행하기**로 토의 시간을 가질 수 있습니다. 이 명령은 개인 선택을 바꾸지 않습니다.
6. 교사 화면에는 닉네임과 구분 번호, 진행 상태, 이야기별 선택 집계가 나타납니다. 닉네임이 같아도 인증 UID로 개인 기록을 따로 유지합니다. **이 집계 공개하기**를 눌러야 학생의 **우리 반 선택** 버튼이 나타납니다. 공개 집계는 그 시점의 스냅샷이며 다시 공개하면 갱신됩니다.
7. 여섯 번째 이야기 뒤 교사가 **학습 정리 함께 열기**를 누르면 모두 결과 화면으로 이동합니다. 학생이 자신의 학습 정리와 PNG 저장을 마친 뒤 **수업 마치기**를 누릅니다. 수업 종료 후에는 새 제출을 받지 않습니다.

교사의 익명 인증은 브라우저 탭 세션에 연결됩니다. 같은 탭을 새로고침하면 **진행하던 수업 열기**가 나타납니다. 탭·브라우저 세션을 닫으면 교사 권한이 사라질 수 있습니다. 학생이 같은 탭에서 새로고침 후 재참여하면 서버에 저장된 사전 정의 선택을 복원하고 **교사의 현재 이야기**로 들어갑니다. 현재 이야기의 대사는 처음부터 다시 나오며, 직접 쓴 문장은 복원하지 않습니다.

## 미리보기와 장애 대응

- **처음 준비 화면**에서 닉네임과 A/B 탐험가를 고른 뒤 **미리보기로 시작**을 누릅니다. 수업 코드는 필요 없고 Firebase 연결을 기다리지 않습니다.
- 미리보기는 처음부터 독립적인 개인 탐험입니다. 닉네임·선택을 서버에 보내지 않으며 교사 진행의 영향을 받지 않습니다.
- 수업 도중에는 미리보기 전환 버튼을 제공하지 않습니다. 연결이 끊기면 안내를 표시하고, 다시 연결되면 교사의 현재 이야기로 이동합니다.
- 미리보기/혼자 하기의 진행은 메모리에만 있습니다. 해당 탭을 닫거나 새로고침하면 새 진행은 사라집니다. 마치기 전에 PNG를 다운로드하세요.
- 게임과 공통 파일을 이미 읽은 화면에서는 수업 서버가 멈춰도 이어갈 수 있습니다. 페이지를 처음 여는 데에는 정적 게임 파일이 필요합니다. 오프라인 설치/PWA를 제공한다고 주장하지 않습니다.

## 저장·권한

Firebase Authentication의 익명 UID와 Cloud Firestore Standard 구조를 사용합니다.

| 경로 | 내용 | 접근 |
|---|---|---|
| `dataV5Rooms/{code}` | 소유 교사 UID, 열린 이야기, 일시정지·종료, 공개 집계 번호 | 인증 후 코드로 직접 조회, 교사만 제어, 수업 목록 탐색 금지 |
| `members/{uid}` | 닉네임, 개인 진행과 사전 정의된 숫자 선택 요약 | 본인 기록만 수정, 본인/해당 교사만 조회 |
| `answers/{uid_scene}` | 학생별 이야기 완료 시 선택 요약 1개 | 본인 제출, 해당 교사 집계. 반복 전송도 같은 문서를 덮어씀 |
| `checkpoints/{uid}` | 진행 중 선택을 포함한 개인 복원 상태 | 해당 학생만 읽고 쓰기. 교사도 읽지 않음 |
| `public/{scene}` | 교사가 명시적으로 공개한 인원수 | 해당 수업 참여자만 공개 중 조회 |

닉네임은 해당 수업의 교사와 학생 본인만 읽을 수 있고, 공개 집계·통합 이벤트·PNG에는 넣지 않습니다. 닉네임을 바꾸고 재참여해도 같은 탭의 개인 기록은 유지합니다. 직접 쓴 기준/약속, 실명, 실제 건강 정보, 연락처, PNG는 전송하지 않습니다. 체크포인트에서 직접 쓴 기준과 그 기록은 제거합니다. 브라우저 세션 저장에는 인증 상태와 방 코드만 남깁니다. Firebase SDK는 디스크 Firestore 캐시를 활성화하지 않습니다.

방은 약 23시간 후 참여·제출을 막습니다. **만료는 서버 데이터 자동 삭제를 뜻하지 않습니다.** 현재 자동 삭제 작업은 없으며, 운영자가 수업 기록이 더 필요하지 않을 때 Firebase Console에서 해당 방과 하위 컬렉션을 함께 정리합니다. 학생 안내대로 실명이나 실제 건강 정보는 입력받지 않습니다.

실제 프로젝트는 `ethicity-reliability-20261114`, Firestore Standard의 서울 리전(`asia-northeast3`)입니다. 익명 인증과 기본 거부 규칙을 사용합니다. 에뮬레이터의 권한·진행·개인 기록 검사 43개를 통과했습니다. 실제 서버 검증 기록은 `tests/QA.md`에 정리하며, 대규모 부하 시험은 포함하지 않습니다.

## 로컬 실행

이미 준비된 이 작업 환경에서는 터미널 2개에서 실행합니다.

```powershell
# 터미널 1: Firebase 로컬 서버
cd data/data_v5/dev
./start-emulators.ps1
```

```powershell
# 터미널 2: 저장소 루트의 정적 서버
cd data/data_v5/dev
./start-web.ps1
```

- 로컬 주소: `http://127.0.0.1:8777/data/data_v5/`. localhost에서는 에뮬레이터 설정이 자동 적용됩니다.
- 로컬 Firebase 프로젝트 ID: `demo-ethicity-data-v5` — 실제 클라우드 프로젝트와 분리됩니다.
- Auth `127.0.0.1:9099`, Firestore `127.0.0.1:8085`, Emulator UI `127.0.0.1:4005`.
- Node 24, Java 21, Python 3을 사용했습니다. 다른 환경에서는 `dev/`에서 `npm ci`를 먼저 실행하고 Java 21 이상을 준비합니다.
- `npm run build`는 로컬 Firebase SDK를 포함한 `classroom.bundle.js`를 만듭니다. CDN에 의존하지 않습니다.

```powershell
cd data/data_v5/dev
npm run build
node ../tests/model.cjs
node ../tests/bridge.cjs
node ../tests/classroom.mjs  # 로컬 Firebase 서버를 켠 뒤 실행
```

`classroom.mjs`는 에뮬레이터의 `TESTCLAS` 방만 시험 자료로 초기화합니다. 실제 프로젝트 연결을 사용하지 않습니다.

## 구현 경계

- `index.html` / `source/classroom.js` / `classroom.css`: 모드 선택, Firebase 연결, 교사·학생 수업 화면.
- `play.html` / `game.js`: 기존 개인 게임. 이야기 입장·선택·이야기 완료·최종 완료에만 수업 브리지를 연결.
- `game-bridge.js`: 같은 출처의 부모 iframe 메시지만 수락하고 교사의 현재 이야기로 즉시 이동. 먼저 완료한 학생의 대기와 개인 선택 보존을 처리하며, 입장 전 미리보기는 독립적으로 실행.
- `classroom-model.js`: 숫자 요약, 자유 입력 제거, 집계와 이야기 잠금 판단.
- `dev/firestore.rules`: 기본 거부, 방 소유권, 학생별 분리, 필드·크기·상태 검사.
- `firebase-config.js`: localhost에서는 로컬 에뮬레이터, 공개 도메인에서는 실제 프로젝트 연결. 포함된 Firebase 웹 설정은 공개 클라이언트 설정이며 관리 자격 증명은 포함하지 않습니다.

## Firebase 배포와 운영

`firebase.json`과 `.firebaserc`는 실제 프로젝트용이며, `dev/firebase.json`은 에뮬레이터용입니다. Google 계정 비밀번호·토큰·서비스 계정 키는 저장소에 포함하지 않습니다.

```powershell
cd data/data_v5/dev
node node_modules/firebase-tools/lib/bin/firebase.js deploy --config ../firebase.json --only auth,firestore:rules --project ethicity-reliability-20261114
```

`tests/production.mjs --run-production-smoke`는 명시적으로 실행할 때만 실제 서버에 임시 QA 방을 만들고 검증 후 종료합니다. 일반 테스트는 실제 수업 데이터를 사용하지 않습니다. 유료 요금제, 자동 삭제, 분석 추적은 활성화하지 않았습니다.
