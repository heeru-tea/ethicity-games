# 신뢰성 · 냠냠봇을 믿어도 될까?

**[게임 바로 플레이](https://ethicity-nyamnyam-v2.hollowcorn.chatgpt.site/data/data_v4/)**

초등 3~4학년이 급식 식단표 AI를 시험하고, 맡은 일과 작동 범위를 확인하며, 사용하는 동안 꾸준히 점검하는 대화형 탐험입니다. 제공된 `scenario_신뢰성_초안_v3.js`를 바탕으로 구성했습니다. 데이터 관리는 세부 활동이며, 게임의 공식 주제는 신뢰성입니다.

## 이야기와 선택

1. **기준:** 예쁜 글씨나 빠르기만으로 확인했을 때의 한계를 비교합니다.
2. **여러 상황:** 네 곳에서 시험합니다. 익숙한 상황 12번과 서로 다른 상황을 구분하며, 같은 시험을 중복 집계하지 않습니다.
3. **맡은 일:** 광고 알림, 허락 없는 건강 기록 접근, 선생님이 맡긴 채소 데이를 구분합니다. 맡은 일 제한과 폴더 접근 권한은 독립적인 설정입니다.
4. **한계:** 처음 식단표와 빠진 기준을 살펴보고 기준 후보를 고릅니다. ‘기타’에서만 자기 생각을 쓸 수 있습니다.
5. **고치고 재시험:** 방법 두 개를 실행합니다. 기준 추가 → 재시험 전 → 시험 → 결과 확인을 별도 상태로 기록합니다. 메뉴마다 남은 항목을 연결하고, 우선 확인할 문제를 고릅니다. 추가로 고치거나 토의할 문제로 남길 수 있습니다.
6. **꾸준한 점검:** 몇 주 뒤 국이 두 가지인 날과 메뉴가 빈 날을 발견합니다. 그대로 쓰거나 멈춰 알리는 선택, 매주 점검할 계획을 기록합니다. 새 오류가 해결되었다고 단정하지 않습니다.

선생님은 모든 경로에서 위험한 메뉴의 사용을 막습니다. 처음 실수해도 나중에 고친 내용은 개선으로 인정합니다. 급식안의 준비 상태를 설명하며 학생에게 점수나 등급을 매기지 않습니다. 잘못된 선택을 유지하는 경우 결과와 미해결 항목이 달라집니다.

## 화면과 조작

- 승인된 기존 크림색 배경, 공식 캐릭터와 학교 배경, 공통 UI를 사용합니다. 공통 패키지나 이전 게임 폴더를 수정하지 않습니다.
- 상단에 **신뢰성**을 모든 기기에서 표시합니다. 장면을 크게, 현재 말풍선을 아래에 하나씩 표시합니다. 배경과 스프라이트는 비율을 유지합니다.
- 자료·선택지·결과를 짧은 단계로 나눕니다. 좁은 세로 화면과 높이가 짧은 가로 화면에 각각 맞춰 배치합니다.
- 터치/버튼으로 완료할 수 있습니다. Tab, Enter/Space, 숫자키 1~4를 지원합니다. 페이지에 표시된 선택지는 최대 두 개이며, 추가 선택지는 다음 쪽에서 고릅니다.
- 설정에서 한 글자씩/한 번에 대화 표시, 효과음, BGM 음량, 움직임 줄이기를 선택합니다. BGM은 제공된 `bgm_4.mp3`이며 시작 조작 뒤 재생합니다. 1.5배 커서 스타일을 유지합니다.
- 탐험가는 A버전/B버전으로 표시하고 가상 학생의 화면 이름은 모두 ‘친구’로 통일합니다.

## 결과 기록과 개인정보

학습한 점 1~3개와 약속 3개를 선택합니다. 약속 하나는 자기 말로 바꿀 수 있습니다. 마지막 약속 후보에는 ‘운영 중 새 오류가 반복되면 다시 점검한다’를 포함합니다.

**개인 리포트 PNG 다운로드**에는 이야기별 선택과 결과, 수정/재시험 이력, 처음과 현재 식단표, 남은 문제, 학습 내용과 약속이 들어갑니다. 긴 기록은 여러 이미지로 나눕니다. 직접 쓴 글도 사용자가 다운로드할 때만 기기에 저장됩니다. 실명·건강 정보를 수집하지 않으며 AI API, 서버 전송, 자동 저장, 진행 저장을 사용하지 않습니다.

## 실행과 통합

GitHub `data` 브랜치의 `data/data_v4/`입니다. 저장소 루트에서 정적 서버를 실행하고 `/data/data_v4/`를 엽니다. 전체 폴더와 `shared/ethicity-elementary-common-v1/`를 함께 배포합니다.

```sh
python -m http.server 8765
node data/data_v4/tests/model.cjs
```

공통 CSS → 게임 CSS, manifest.js → common.js 순서로 로드합니다. `gameId`는 기존 통합용 `data`를 유지합니다. 이벤트는 `ethicity:ready`, `ethicity:progress`(total 6), `ethicity:complete`(`result: { completed: true }`), `ethicity:exit`입니다. 입력 글과 선택 이력을 이벤트에 넣지 않습니다.

원본 시나리오의 ID는 추적용으로 유지하지만 기존 응답 ID는 현재 작동 기록 의미로 사용합니다. 방문하지 않은 연습을 했다고 말하지 않도록 일부 대사를 상황에 맞게 정리했고, 허락 없는 접근과 땅콩 메뉴는 서로 다른 문제로 설명합니다. 기준 후보 선택과 다운로드 안내는 앞서 확정한 사용 방식에 맞췄습니다.

## 검증

- 8,192가지 조합: 독립적인 기준·시험·권한, 메뉴별 남은 문제, 급식안 상태와 안전 확인.
- 기준을 추가해도 재시험 전에는 통과 처리하지 않음. 시험 중복 집계 방지. 최초 기록과 선택 이력 보존.
- 실제 브라우저에서 문제 수정 후 완료 경로와 미해결 상태로 완료하는 경로 확인. PNG 생성·다운로드 및 실제 이미지 확인.
- 모바일·태블릿·데스크톱에서 상단 제목, 주요 선택지, 자료 및 결과 페이지 배치 확인.
