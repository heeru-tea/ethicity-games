# 급식 메뉴 AI ‘냠냠봇’

**[게임 바로 플레이](https://ethicity-nyamnyam-v2.hollowcorn.chatgpt.site/data/data_v3/)**

초등 3~4학년이 디지털 설문으로 급식 의견을 수집하고, 데이터가 AI의 결과에 미치는 영향을 살펴보는 대화형 게임입니다. 메뉴별로 남은 확인 항목을 읽고, 데이터를 고친 뒤 메뉴가 어떻게 달라지는지 비교합니다.

## 이번 수정

- 중앙의 큰 장면, 아래쪽의 현재 말풍선 하나, 선택 버튼 순서로 배치했습니다. 장면이 바뀌면 앞선 대화를 지웁니다.
- 모든 기기에서 긴 내용을 작은 단계로 나눕니다. 탐험 안내는 3단계, 긴 선택지는 2~4개씩, 급식표는 요일별 한 장씩, 결과는 급식안 → 발견한 점 → 남은 확인 항목 → 학습 내용 → 약속 → 마지막 확인의 6단계로 제공합니다. 장면 크기를 화면 높이에 맞춰 조절합니다.
- 탐험가는 A버전 탐험가 / B버전 탐험가 중 고릅니다. 학생 캐릭터 표시는 모두 ‘친구’로 통일하고, 필요한 경우 장소를 덧붙입니다. 공식 캐릭터 ID·이미지는 유지합니다.
- 화면의 게임 제목에 버전 번호를 표시하지 않습니다. ‘학습한’, ‘수집하기’로 용어를 정리했습니다.
- 날씨/의자 수를 선택한 결과, 반복·가짜 응답을 남긴 결과, 부적절한 개선 방법을 실행한 결과를 각각 보여 줍니다. 오류 선택을 강제로 되돌리지 않고, 이후에 고칠 수 있습니다.
- 설문 질문은 후보에서 선택합니다. ‘기타’에서만 자기 질문을 쓸 수 있습니다. 후보를 고르는 것과 실제 질문을 추가·응답 확인하는 활동을 구분합니다.
- 처음 개선 방법 두 개를 실행한 다음, 각 메뉴에 ‘아직 확인할 것’을 연결합니다. 남은 문제가 있으면 ‘남은 문제 중 무엇부터 확인할까?’를 반드시 묻습니다. 지금 확인하거나 토의할 문제로 남길 수 있습니다.
- 결과 화면에서 학습한 점 1~3개와 약속 3개를 고릅니다. 완료 화면의 **개인 리포트 PNG 다운로드**로 이야기별 선택·결과·수정 이력, 처음/현재 급식안, 남은 문제, 학습 내용과 약속을 저장합니다. 긴 기록은 여러 PNG로 나뉘며 각 장을 저장할 수 있습니다.

## 조작과 개인정보

- 버튼/터치만으로 완료할 수 있습니다. Tab 이동, Enter/Space 선택, 숫자 1~4로 앞의 선택지 선택, Space로 다음 대사를 지원합니다.
- 장면의 긴 자료와 메뉴는 ‘이전 자료 / 다음 자료’ 버튼으로 한 장씩 읽습니다. 긴 선택지는 ‘앞 선택지 / 다음 선택지’로 넘깁니다. 좁거나 짧은 화면에서도 작은 단계를 차례대로 확인할 수 있습니다.
- 설정에서 한 글자씩/한 번에 대화 표시, 효과음, BGM 음량, 움직임 줄이기를 바꿀 수 있습니다. 배경음악은 제공된 `assets/bgm_4.mp3`이며 시작 조작 후 재생됩니다.
- 실명이나 건강 정보를 입력받지 않습니다. 실제 학생의 설문을 수집하지 않습니다. 모든 등장인물의 정보는 시나리오 속 가상 자료입니다.
- 선택과 직접 쓴 글은 메모리에만 유지합니다. 자동 저장·서버 전송하지 않습니다. 사용자가 요청한 PNG에만 직접 쓴 질문/약속이 포함됩니다. 새로고침·다시 시작 시 진행은 지워집니다.

## 실행과 공통 패키지

GitHub `data` 브랜치의 `data/data_v3/`가 소스 위치입니다. 프로젝트 루트에서 정적 서버를 실행한 뒤 `/data/data_v3/`를 엽니다.

```sh
python -m http.server 8765
```

`../../shared/ethicity-elementary-common-v1/`의 manifest/runtime/배경/캐릭터/UI/효과/SFX/폰트를 그대로 불러옵니다. 공통 폴더와 이전 게임 파일은 수정하지 않습니다. AI API, 이동 엔진, 반복 타일맵을 사용하지 않습니다.

통합 이벤트는 `ethicity:ready`, `ethicity:progress`(전체 6개 이야기), `ethicity:complete`(`result: { completed: true }`), `ethicity:exit`입니다. `gameId`는 `data`입니다. 입력 글·선택 이력·개인 리포트는 이벤트에 넣지 않습니다.

## 확인

```sh
node data/data_v3/tests/model.cjs
```

- 4,096가지 수집·정리·설문·정보관리 조합에서 분기와 결과를 확인했습니다.
- 모든 미해결 데이터 문제가 적어도 한 메뉴에 연결되고, 수정한 항목이 메뉴에서 사라지는지 확인했습니다.
- 브라우저에서 오류 선택 후 일부만 고친 경로, 모든 곳을 수집하고 두 설문을 추가한 경로를 확인했습니다.
- 개인 리포트 PNG의 실제 다운로드와 이미지 내용을 확인했습니다.
- 430×932, 760×1000, 1024×768에서 주요 게임·선택·결과 화면의 세로/가로 넘침, 자료 잘림과 단계 이동을 확인했습니다. OS 글자 확대·매우 작은 높이에서는 접근성을 위해 자연스러운 스크롤을 허용합니다.
