# 급식 메뉴 AI ‘냠냠봇’

윤리시티 · AI 윤리 탐험대의 데이터 관리 미니게임입니다. 초등 3~4학년 대상, 예상 8~10분의 메신저형 개인 활동이며 AI API나 서버가 필요하지 않습니다.

## 실행

저장소의 `data/index.html`을 브라우저에서 열면 됩니다. `data/`와 `shared/ethicity-elementary-common-v1/`를 함께 유지해야 합니다. 웹 서버에서는 `/data/`로 접근합니다. 외부 CDN·온라인 폰트·API를 사용하지 않아 파일을 내려받은 뒤 오프라인으로 진행할 수 있습니다.

`START → INTRO → RULE → 장면 0~5 → RESULT → COMPLETE` 흐름입니다. 대사는 타자 치듯 글자마다 나타납니다. 표시 도중 다음 버튼·대화창·Space를 누르면 현재 문장만 완성하고, 한 번 더 누르면 다음 대사로 넘어갑니다. 플레이어가 고른 답은 즉시 표시합니다. 이전 장면까지 위로 스크롤해 다시 읽을 수 있고, 드래그 없이 선택 버튼만으로 완료합니다.

## 공통 자산 연결

- 공통 패키지: `../shared/ethicity-elementary-common-v1/`
- manifest ID/version: `ethicity-elementary-common` / `1.0.0`
- `common.css` → 전용 CSS, `manifest.js` → `common.js` → `story.js` → `game.js` 순서입니다.
- 공식 ID 8명만 사용합니다. `robot`의 이 게임 표시 이름은 냠냠봇입니다. 플레이어는 초상화 없는 오른쪽 ‘나’ 말풍선입니다.
- 프로필은 공식 portrait PNG와 manifest의 표정 순서를 사용합니다. 캐릭터를 다시 그리지 않습니다.
- 장소는 `courtyard`, `cafeteria`, `classroom`, `library`입니다. 1학년 교실 앞은 공통 교실 이미지와 장소 이름으로 표현합니다. 별도 복도 자산은 만들지 않았습니다.
- `.ee-*` UI, Galmuri11, 공통 아이콘·SFX와 `drawEffect`를 사용합니다. CSS는 `.game-data` 아래에 둡니다.
- 이 게임은 이동형 탐험이 아닙니다. 이동 엔진, `walkAreas`, 새 타일맵, BGM을 추가하지 않습니다.
- `data` 브랜치에는 공통 패키지가 없었으므로 `main`의 `e913b3795b249b03f84b17b86ab079928e46691d`에서 패키지 91개 파일을 그대로 가져왔습니다. 공통 패키지 트리 SHA는 `2dfcf6c4051ed3a8938c5207deb05eb2b0234603`입니다.

## 대화와 장면 연출

- NPC의 말은 글자당 약 30ms, 문장 부호 뒤는 140ms 간격으로 나타납니다. 스크린 리더에는 완성된 문장을 한 번 알립니다. 지난 대화에는 처음부터 완성된 문장을 보관합니다.
- 설정의 ‘문장을 한 번에 보여 주기’ 또는 ‘움직임 줄이기’를 켜면 타자 효과를 생략합니다. 화면 전환·재시작·설정창 열기 시 남은 타이머를 정리합니다.
- 왼쪽 장면은 방문 장소·정리 중인 카드·급식표·정보 보호 대화에 맞춰 바뀝니다. 말하는 인물의 공식 portrait와 표정도 함께 바뀌고, 학교 장면의 인물은 `drawCharacter`와 공식 walk sheet의 정지 프레임으로 표시합니다.
- 급식표는 실제 분기의 메뉴 데이터로 그립니다. 처음 만든 급식표와 수정된 급식표가 대화 내용과 일치합니다. 모바일에는 그림·현재 화자를 작게 배치하고 급식표 전체는 대화 기록에서 읽습니다.
- 공통 팩에 없는 사건 클로즈업 3장만 내장 `image_gen`으로 만들었습니다. 공식 학교 배경·캐릭터·아이콘을 대체하지 않습니다. 생성 프롬프트 원문은 `assets/generation.json`에 있습니다.

| 게임 전용 그림 | 쓰는 장면 |
| --- | --- |
| `assets/opinion-box.png` | 의견함에 한꺼번에 쌓인 카드, 의견함 지키기 |
| `assets/sorting-cards.png` | 중복·이름 도용·진짜 의견을 하나씩 살펴보기 |
| `assets/protected-surveys.png` | 질문지를 필요한 사람만 보고 안전하게 보관하기 |

세 그림은 1536×1024 PNG이며 따뜻한 크림·세이지·목재 색과 픽셀 표현을 사용합니다. 인물·읽을 수 있는 개인정보는 포함하지 않습니다. 그림은 실행 시 로컬에서 미리 불러오고 게임 중에는 이미지 생성이나 네트워크 요청을 하지 않습니다.

## 상태와 분기

모든 상태는 메모리에만 있습니다. `story.js`에 대사, 자료, 메뉴·결과 계산을 모았습니다.

| 상태 | 의미 |
| --- | --- |
| `visited` | 의견함·지호·새봄·하늘 방문, 최대 4곳 |
| `sort` | 중복 카드·사칭 카드·맞춤법이 틀린 진짜 의견의 최종 넣기/빼기 |
| `boxProtection` | 의견함 보호 방식 |
| `methods`, `questionImproved` | 개선 방법 2개와 질문지 보완 여부 |
| `protectChoices` | 질문지 공개·보관 선택 2개 |
| `words`, `pledges` | 낱말 카드 5개와 선택한 약속 3개 |

장면 0은 틀려도 설명을 읽고 다시 고릅니다. 날씨와 의자 수도 데이터일 수 있지만, 이 질문의 목적은 급식 선호를 알아보는 것임을 설명합니다.

장면 2는 즉시 피드백 후 다시 고치거나 현재 선택을 유지할 수 있습니다. 다시 고치면 최종 선택으로 계산합니다. 처음의 실수를 학생 평가로 남기지 않습니다. 장면 4의 함정은 선택 수에 포함하지 않으며 다른 방법을 고를 수 있습니다.

첫 급식표는 장난 카드가 남았으면 짜장면 반복·땅콩버터 피자, 장난 카드를 뺐지만 일부 장소만 방문했으면 매운 메뉴·땅콩 소스 치킨 중심, 네 곳을 모두 방문했으면 카레·김밥·짜장밥을 섞습니다. 모든 경로에서 질문지의 ‘못 먹는 음식’ 칸 누락을 발견하고 실제 식사 전에 선생님이 중단합니다. 대사는 실제로 표시된 요일·메뉴에 맞춥니다.

최종 메뉴는 모든 경로에서 선생님이 위험한 재료를 제외한 개선안입니다. 세 결과 이름은 학생이 아닌 급식표의 준비 상태를 설명합니다.

- **모두가 맛있는 급식:** 네 곳 방문, 장난 카드 제거, 진짜 의견 유지, 질문지 보완, 의견함 보호, 질문지 보호 선택 2개를 모두 갖춘 경우.
- **다시 짜 볼 급식:** 장난 카드가 남았거나, 일부 장소만 방문하고 질문지 보완도 하지 않은 경우. 개선안은 보여 주되 자료를 다시 정리한 후 확정한다고 설명합니다.
- **조금 더 살펴볼 급식:** 그 밖의 경우. 실제로 남아 있는 확인 사항을 표시합니다.

결과 화면은 실제 선택에서 도출한 발견 3문장, 낱말 카드 5장, 선택 약속 3개, 기억할 한 문장을 제공합니다. 사람의 점수·등급은 표시하지 않습니다.

## 개인정보와 통합

이름 입력, localStorage/sessionStorage/IndexedDB, 쿠키, 분석 도구, fetch/API 호출이 없습니다. 선택 성찰과 직접 고친 약속은 화면에서만 사용하고 이벤트에도 넣지 않습니다. 새로고침·처음부터 시작 시 사라집니다.

현재 창의 CustomEvent와 iframe 부모의 postMessage로 다음 이벤트를 보냅니다.

| 이벤트 | 내용 |
| --- | --- |
| `ethicity:ready` | `{ type: 'ethicity:ready', gameId: 'data' }` |
| `ethicity:progress` | `{ type: 'ethicity:progress', gameId: 'data', current: 1..6, total: 6 }`, 각 장면 종료 시 |
| `ethicity:complete` | `{ type: 'ethicity:complete', gameId: 'data', result: { completed: true } }`, 약속 3개 확정 후 한 번 |
| `ethicity:exit` | `{ type: 'ethicity:exit', gameId: 'data' }`, 통합 페이지로 돌아가기 요청 |

통합 페이지는 메시지의 `event.source`가 해당 iframe인지 확인하고 `gameId`와 `type`을 검사합니다. `ethicity:exit` 수신 시 게임 목록을 표시합니다. 단독 실행에서는 같은 출처의 이전 페이지가 있으면 돌아가며, 없으면 게임 목록 탭으로 돌아가도록 안내합니다. 공통 패키지에 통합 페이지 자체는 포함되어 있지 않습니다.

## 접근성과 조작

- 실제 button, 선택 상태 `aria-pressed`, 키보드 초점 표시, 상태 알림을 사용합니다.
- Tab 이동, Enter/Space 선택, 숫자 1~4로 앞의 네 선택지 선택, Space 다음 대사를 지원합니다. 5~6번째 선택지는 Tab으로 접근합니다.
- 입력 칸에서는 숫자·Space 단축키를 실행하지 않습니다.
- 효과음은 기본 꺼짐입니다. 설정에서 사용자가 켠 뒤 공통 SFX를 재생합니다.
- `prefers-reduced-motion`과 게임의 움직임 줄이기 설정을 반영합니다.
- 760px·430px에서 대화 영역은 스크롤하고 선택 버튼은 아래에 유지합니다.
- 정확한 답이 있는 퀴즈·카드 정리·개선 방법에만 correct/retry 효과를 사용합니다.

## 검증

`node data/tests/verify.cjs`는 2,880개 상태 조합, 세 결과, 개선 급식표의 위험 재료 제외, 자산 50개 경로, 공통 패키지 91개 파일의 원본 일치를 검사합니다. 원본 비교에는 `origin/main` 참조가 필요합니다.

`data/tests/browser.cjs`는 Playwright와 설치된 Microsoft Edge로 실제 UI 전체 진행을 검사합니다. Playwright를 개발 환경에 설치하거나 `NODE_PATH`로 제공한 후 `node data/tests/browser.cjs`를 실행합니다. `ETHICITY_EDGE_PATH`로 Edge 실행 파일 경로를 지정할 수 있습니다. 게임 실행에는 이 도구가 필요 없습니다.

브라우저 검증은 데스크톱 1280×900, 760×900, 모바일 430×932에서 수행하며 파일 직접 열기, 세 분기 완료, 재선택, 터치·키보드, 동작 줄이기, 자유 입력 탈출 처리, 통합 이벤트, 외부 요청·저장 호출·오류를 확인합니다. 430×740에서는 타자 효과의 점진 표시, 탭으로 완성한 뒤 다음 대사로 이동하기, 자연스러운 표시 완료, 즉시 표시 설정, 실행 중 reduced motion 변경, 재시작 시 타이머 취소를 추가로 확인합니다. 방문 장소와 사건 그림의 연결도 검사합니다. 스크린샷과 결과는 Git에서 제외한 `data/tests/artifacts/`에 생성됩니다. 실제 학생의 8~10분 이용 시간과 실제 휴대폰·스피커 사용감은 별도 수업 확인 대상입니다.
