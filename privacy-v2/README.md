# 프라이버시 보호 v2 — 친구와 대화하는 버전

2026-10-18 수정본입니다. 기존 `../privacy/` 폴더는 수정하지 않고 보존합니다.

## 실행 주소

- [새 버전 교사 컨트롤타워](https://ethicity-privacy-20261011.web.app/privacy-v2/?mode=teacher)
- [새 버전 학생·혼자 탐험](https://ethicity-privacy-20261011.web.app/privacy-v2/)
- [기존 버전](https://ethicity-privacy-20261011.web.app/privacy/)

실시간 수업은 교사 주소에서 **새 수업 만들기 → 학생 입장 링크 복사 → 학생에게 공유 → 1라운드 시작하기** 순서로 진행합니다. Google 로그인은 필요하지 않으며 인터넷 연결은 필요합니다. 학생에게 일반 게임 주소 대신 해당 수업의 입장 링크를 전달합니다. 같은 기기·브라우저로 다시 열어야 만든 수업을 이어서 조작할 수 있습니다.

## 달라진 점

- 안내·선택지·결과·완료 카드의 문장을 ‘~합니다’체로 통일합니다.
- 참가자를 닉네임으로 부르지 않고 서술에서는 ‘당신은’, 대화의 화자 표시는 ‘당신’으로 표시합니다.
- 도입, 8개 사례, 32개 선택 결과, 3개 엔딩에 친구와 나누는 대화를 넣었습니다. 친구의 이름은 처음에 직접 정합니다.
- 서로 다른 말풍선과 원본 캐릭터 그림으로 친구와 참가자를 구분합니다. 대화도 순서대로 타이핑되며 화면을 클릭하거나 Enter·스페이스 키를 누르면 현재 글을 바로 펼칩니다.
- 기존 8개 사례·각 4개 선택지·5개 학습 요소·3개 엔딩·원본 이미지·나눔스퀘어라운드 글꼴을 유지합니다.

## 버전 구분

| 폴더 | 용도 | 말투·호칭 |
|---|---|---|
| `privacy/` | 기존 v1 보존 | ~해요, 닉네임 서술 |
| `privacy-v2/` | 이번 v2 대화형 | ~합니다, 당신은, 친구와 대화 |

두 버전의 실시간 수업 목록과 진행 중인 기록은 구분합니다. v1 수업은 v1에서, v2 수업은 v2에서 엽니다. 학생에게 교사가 생성한 같은 버전의 입장 링크를 전달합니다.

## 파일 구성

- `index.html`: 그림·글꼴·시나리오를 내장한 실행 파일입니다. 내려받아 열면 혼자 탐험을 할 수 있습니다.
- `scenario.json`: 대사·선택지·친구의 반응·학습 요소를 읽기 편하게 별도 제공한 원본입니다. 실행 HTML 안의 `game-data`에도 같은 내용이 들어 있습니다. 이 JSON만 고쳐서는 이미 배포한 HTML이 바뀌지 않습니다.
- `시나리오.html`: 8개 사례와 선택별 결과·학습 요소를 정리한 문서입니다.
- `database.rules.json`: v1 규칙을 보존하고 v2 수업 규칙을 추가한 배포용 규칙입니다.
- `NanumSquareRound-LICENSE.txt`: 포함한 글꼴의 이용 조건입니다.

## 통합 허브의 저장 형식

게임 코드는 여전히 `privacy`입니다. `privacy-v2`는 버전 폴더 이름이며 새로운 윤리 요소가 아닙니다.

```json
{"character":"char_03","nickname":"별고래"}
```

위 값은 `ethicity.player`에 저장합니다. 닉네임은 설정·기록용으로만 보관하며 이야기에서 참가자를 부르는 데 사용하지 않습니다.

```json
{"game":"privacy","completed":true,"ending":"A","card":"개인정보는 모을 때부터 지울 때까지 보호합니다."}
```

완료 값은 `ethicity.result.privacy`에 저장합니다. 같은 사이트에서 두 버전을 완료하면 이 공통 완료 값은 마지막으로 완료한 버전의 값으로 갱신됩니다. 한 줄 카드는 40자 이내이며, 이번 요청에 따라 ‘~합니다’체입니다. 닉네임과 가상 친구 이름은 서버로 보내지 않습니다.
