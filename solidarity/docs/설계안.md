# 설계안 · 연대성 「성적표의 비밀」 (Prompt 5 형식)

GAME ID `solidarity` · 일반 미니게임형(실시간 학급 진행) · 초등 5~6학년 · 약 40분 · 공통 팩 `ethicity-elementary-common-v1` 1.0.0

## 1. 한 문장 게임 요약
반 전체가 무작위 AI 요금제로 같은 시험을 보고, 성적표가 보여 주는 격차를 자료로 살펴본 뒤, 재시험 규칙과 다음 학년에게 남길 규칙 한 줄을 함께 정한다.

## 2. 화면/장면 목록과 전환도
```
[첫 화면 courtyard] ─교실 열기→ [선생님 화면 ?teach] ─QR→ [별명 입력 ?room]
학생: 입장 대기 → 요금제 뽑기 → 1교시 → 1교시 성적표 → 공정성 미니게임(배달/실험실/채점기)
      → 선택의 갈림길 → 학급 회의 투표 → 2교시 → 2교시 성적표 → 서약 → 다음 학년 규칙 투표 → 엔딩
선생님: 같은 10단계를 「다음 단계로 넘기기」로 진행, 집계(평균·투표·기분·서약·다음 학년 규칙)를 본다.
```

## 3. 상태 모델
- 서버 `RoomState`(원본 그대로): `stage`, `players[{id,name,plan,effectivePlan,sharedTurns,online,progress,score1,score2,voted,pledged}]`, `policy`, `tally{keep,basic-for-all,shared-seats}`, `moods`.
- 클라이언트 로컬: 시험 답안·AI 힌트·광고 타이머, 미니게임 진행, 딜레마 선택, 서약 선택, 다음 학년 규칙 선택(`legacy`), 효과 토큰.
- 저장: 별명·교실 토큰·소리 설정·(검사용) 서버 재정의.

## 5. 공통 팩에 없어서 새로 필요한 게임 전용 asset
코덱스 납품(ethicity-extra-v1 1.1.0) 12종: 요금제 카드 5장(`sd_plan_*`), 시험지(`sd_exam_sheet`), 성적표 종이(`sd_report_sheet`), 이용권(`sd_ticket`), 도움 창구 책상(`sd_helpdesk`), 규칙 게시판(`sd_rule_board`), 투표 손(`sd_vote_hand`), 편지 카드(`sd_future_card`). `assets/manifest.json` 에 등록된 파일을 우선 쓰고, 없으면 임시 픽셀 그림·공통 소품으로 돌아간다. 그 밖의 인물·배경·아이콘·효과는 만들지 않는다.

## 8. CSS namespace 계획
`body.game-solidarity` 아래 `sd-*` 보조 클래스만 정의한다. `.ee-*` 의 색·테두리·글꼴은 건드리지 않고 폭(`sd-wide`)·간격·배치만 더한다. 페이지 바탕은 `--ee-paper`.

## 9. 저장 키 계획
`ethicity.solidarity.name` · `ethicity.solidarity.avatar` · `ethicity.solidarity.token.<코드>` · `ethicity.solidarity.sound` · `ethicity.solidarity.server`(session). 옛 `ethicity.player`·`ethicity.result.*` 미사용.

## 10. 모바일 조작 계획
모든 조작은 실제 `<button>` 탭. 이용권 배달은 장면 위 투명 버튼(친구 자리)을 탭해 전달, 드래그 없음. 430px 에서는 맨 앞 친구의 말풍선만 보이고 이름표는 발밑에 붙는다. 430px 에서 말풍선 꼬리가 위로 돌고(공통 CSS), 얼굴이 말풍선 위에 놓인다. 표는 가로 스크롤 영역 안에 둔다.

## 11. 키보드/접근성 계획
Tab/Enter·Space 로 전 흐름 완료. `aria-pressed`(선택·탭·단계), `role=group`+`aria-label`(보기·규칙·서약), `role=dialog aria-modal`+초점 가두기(광고), `role=status aria-live`(힌트·배달 안내), 장면 캔버스는 `role=img`+설명. 상태를 색만으로 구분하지 않고 글자·아이콘을 함께 쓴다. `prefers-reduced-motion` 에서 효과는 정지 프레임, 애니메이션 즉시 전환.

## 12. 통합 이벤트 계획
`ready`: 공통 팩 이미지 로드가 끝난 뒤 1회. `progress`: 수업 단계 변경마다 `current=단계번호, total=10`(학생·선생님). `complete`: 학생이 서약하고 다음 학년 규칙에 투표한 뒤 1회, `result:{completed, role, plan, policy, legacyRule}`(별명 없음).

## 13. 탐험형 stage 계획
해당 없음. 장면 그림은 1280×720 논리 좌표의 공통 배경을 세로로 잘라 띠 그림(1280×400~480)으로 그리며 `image-rendering: pixelated`.

## 14. 공통 SFX/effect 사용 계획
4번 표와 같다. BGM 없음. 효과음은 사용자 조작 뒤에만 재생하고 소리 토글로 끈다.

## 15. 실패 가능성이 높은 부분과 대응
- 서버 연결 실패(오프라인): 연결 중 안내 + 자동 재접속(기존 훅). `?server=` 로 로컬 Worker 검사.
- 공통 팩 경로 오류: `index.html` 이 `../shared/...` 상대경로를 쓰므로 게임 폴더는 `shared/` 와 형제여야 한다. 이미지 로드 실패 시 CSS 스프라이트 UI 는 계속 동작하고 장면 캔버스만 비는 정도로 격리.
- 정책 투표와 다음 학년 투표가 같은 `vote` 메시지를 쓰는 점: 정책은 2교시 전 `closeVote` 로 고정되므로 안전하며, 선생님 화면은 서약 단계에서만 집계를 다음 학년 규칙으로 해석한다.
- 글꼴 늦게 로드 시 캔버스 카드 글자: `document.fonts.ready` 뒤 다시 그린다.
