교사 화면 열기 · 학생·혼자 탐험 열기

  1. 교사는 새 수업을 만들고 학생 입장 링크를 공유합니다.
  2. 학생은 설정과 도입을 마친 뒤 ‘수업에 입장합니다’를 누릅니다. 교사 명단에 닉네임이 나타납니다.
  3. 교사는 ‘1라운드 시작하기’로 시작합니다. 선택을 받은 뒤 결과를 공개하고 다음 라운드로 넘어갑니다.
  4. 집계와 명단의 ‘크게 보기 ↗’를 누르면 별도 창으로 열립니다. ‘현재 화면 확대’도 사용할 수 있습니다. 확대 화면의 ‘화면 가득 보기’를 누르면 전체 화면이 됩니다.
  5. 마지막 라운드 뒤 수업을 마무리합니다. 필요한 CSV를 내려받고 수업 기록을 정리합니다.

새 창은 같은 브라우저에서 사용합니다. 입장 명단은 현재 접속 여부가 아닌 입장 기록입니다. 혼자 탐험은 다운로드한 index.html로 실행할 수 있습니다.

항목결과
✔ 단일 HTML·외부 요청혼자 탐험은 내장 이미지·글꼴로 오프라인 실행합니다. 실시간 수업은 승인된 Firebase 네트워크 연결을 사용합니다.
✔ 캐릭터·닉네임 저장ethicity.player의 두 필드를 유지합니다. 요청에 따라 시작할 때 설정을 표시합니다.
✔ 완료 저장·카드ethicity.result.privacy의 네 필드를 유지합니다. 카드 40자 이내, 요청한 ~합니다체입니다.
✔ 라운드·선택지·엔딩변경 요청에 맞춰 8라운드, 각 4개 선택지, 엔딩 3종입니다.
✔ 학습 요소·꼬리표지식·이해 2개, 기능 2개, 가치·태도 1개입니다. 선택 전에는 학습 요소를 숨기고, 선택 결과에서 번호와 뜻을 표시합니다.
✔ 시나리오 분리HTML의 game-data에 모으고 진행 코드와 분리합니다. 별도 JSON도 제공합니다.
✔ 말투·용어·아이콘설명은 당신은·~합니다, 친구 대화는 이번 요청의 자연스러운 말투입니다. ✔·!·✖와 문장으로 구별합니다.
✔ 이름 입력·가상 정보승인한 가상 닉네임·친구 이름 입력만 제공합니다. 한글 1~5자·부적절한 표현 검사를 적용합니다.
✔ 실시간 명단·확대교사 화면에 닉네임을 실시간 표시하고 선택 집계·입장 명단을 각각 확대합니다.
✔ 기존 버전 보존v1·v2 HTML과 기존 서버 규칙의 동일성을 확인했습니다.

최초 요구와 달라진 항목은 이후 승인한 변경 요청을 기준으로 점검했습니다.
