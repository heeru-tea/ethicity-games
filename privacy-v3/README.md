# 프라이버시 보호 ver3 · 친구와 함께 살펴보는 AI 비서

2026-10-18 수정본입니다. 기존 `privacy/`와 `privacy-v2/`는 그대로 보존하고 `privacy-v3/`를 추가했습니다.

## 실행

- [ver3 교사 컨트롤타워](https://ethicity-privacy-20261011.web.app/privacy-v3/?mode=teacher)
- [ver3 학생·혼자 탐험](https://ethicity-privacy-20261011.web.app/privacy-v3/)

교사는 **새 수업 만들기 → 학생 입장 링크 복사 → 학생에게 공유 → 1라운드 시작하기** 순서로 진행합니다. 학생에게는 일반 게임 주소 대신 **그 수업의 입장 링크**를 공유합니다. 학생은 캐릭터·닉네임·가상 친구 이름을 정하고 도입 대사를 읽은 뒤 **수업에 입장합니다**를 누릅니다. 이때 교사 명단에 닉네임이 나타납니다. Google 로그인은 필요하지 않습니다. 실시간 수업에는 인터넷이 필요합니다.

## 교사 확대 화면

1. **선택 집계 크게 보기 ↗**: 선택별 인원을 별도 창에 크게 표시합니다.
2. **입장 명단 크게 보기 ↗**: 닉네임·이번 선택·진행 상태를 별도 창에 크게 표시합니다.
3. 새 창의 **화면 가득 보기**를 누르면 전체 화면을 사용합니다. Esc 키로 나옵니다.
4. **현재 화면 확대**를 누르면 새 창 없이 해당 패널만 크게 표시합니다. **교사 전체 화면으로**를 누르면 돌아갑니다.

확대 화면도 실시간으로 갱신됩니다. 브라우저에서 새 창이 차단되면 현재 화면 확대를 사용합니다. 확대 창은 수업을 만든 것과 같은 기기·브라우저에서 엽니다. 학생에게는 확대 창 주소를 공유하지 않습니다. 연결 오류가 나면 **수업 다시 연결**을 사용합니다.

입장 명단은 입장 기록입니다. 창을 닫거나 인터넷이 끊긴 학생도 명단에 남으므로 현재 접속 중이라는 뜻은 아닙니다. 같은 닉네임은 입장 순서로 구별합니다. 응답 수집 중 집계는 교사용이며, 학생에게 결과를 보여 줄 때는 **응답 마감 · 결과 공개**를 누릅니다. 기록 CSV에 닉네임도 포함됩니다.

## 친구와의 대화

도입은 요청한 다음 대사로 시작합니다. 이름은 학생이 정한 값으로 바뀝니다.

> [친구 이름]: [닉네임]! 이번에 내가 새로운 AI비서를 사용하게 됐는데, 내가 뭔가를 시키면 내 정보를 알려달라고 말해. 그런데 내 정보를 그냥 막 제공해도 되는지 헷갈려. [닉네임]한테 도움을 요청해도 될까?

8개 사례의 대화, 32개 선택 뒤 친구의 반응, 3개 엔딩의 친구 대사를 편안한 말투로 바꿨습니다. 설명·선택지·학습 안내는 ‘당신은’과 ‘~합니다’를 유지합니다. 대사는 순서대로 타이핑되며 말풍선·화면 클릭 또는 Enter·스페이스 키로 모두 펼칩니다. 원본 이미지와 나눔스퀘어라운드 글꼴을 유지합니다.

## 저장하는 내용

- 닉네임과 가상 친구 이름은 한글 1~5자입니다. 비속어 목록과 반복 글자를 검사합니다. 모든 부적절한 표현을 완벽히 판단하는 AI 검사는 아닙니다.
- 실시간 수업에서는 학생이 정한 **가상 닉네임**, 입장 시각, 선택, 완료 결과를 서버에 저장하고 수업을 만든 교사에게 표시합니다. 다른 학생의 기록은 학생끼리 읽을 수 없습니다.
- 가상 친구 이름은 서버로 보내지 않습니다. 실명·학교·연락처·실제 사진은 입력하지 않습니다. 수업 종료 후 필요한 CSV를 받은 다음 **이 수업 기록 삭제**로 정리할 수 있습니다.
- 혼자 탐험은 서버 연결 없이 진행합니다. 저장이 차단된 환경에서도 게임은 끝까지 진행할 수 있습니다.

## 버전별 폴더

| 폴더 | 버전 | 특징 |
|---|---|---|
| `privacy/` | v1 보존 | ~해요, 닉네임 서술 |
| `privacy-v2/` | v2 보존 | ~합니다, 당신은, 격식 있는 친구 대화 |
| `privacy-v3/` | 이번 ver3 | 자연스러운 친구 대화, 실시간 닉네임 명단, 별도 확대 화면 |

실시간 수업과 임시 진행 기록은 버전별로 구분됩니다. 이전 수업은 해당 버전에서 엽니다. 교사의 수업 열쇠는 브라우저에 보관되므로 같은 기기·브라우저·주소를 사용합니다. 사이트 저장정보를 지우거나 비공개 창을 닫으면 이전 수업에 접근하지 못할 수 있습니다.

게임 코드는 계속 `privacy`입니다. 공통 저장 형식은 다음과 같습니다.

```json
{"character":"char_03","nickname":"별고래"}
```

`ethicity.player`에 저장합니다. 캐릭터 ID는 팀 공통 ID 확정 전 임시 ID입니다.

```json
{"game":"privacy","completed":true,"ending":"A","card":"개인정보는 모을 때부터 지울 때까지 보호합니다."}
```

`ethicity.result.privacy`에 저장합니다. 같은 사이트에서 다른 버전을 완료하면 이 공통 완료 값은 마지막 완료 결과로 갱신됩니다. 한 줄 카드는 40자 이내입니다.

## 파일

- `index.html`: 이미지·글꼴·시나리오를 내장한 게임 파일. 내려받아 열면 혼자 탐험을 할 수 있습니다.
- `scenario.json`: 대사와 선택지의 별도 원본. 실행 HTML의 `game-data`에도 같은 내용이 있으며 이 JSON만 바꾸면 배포 화면은 바뀌지 않습니다.
- `시나리오.html`: 라운드별 대화·위험 신호·선택·결과·학습 요소·엔딩 문서.
- `사용안내.html`: 수업 진행법과 자체 점검표.
- `database.rules.json`: 기존 `rooms`와 `roomsV2`를 보존하고 `roomsV3`를 추가한 서버 규칙.
- `검증결과.json`: 자동 검사와 브라우저 확인 범위.
- `NanumSquareRound-LICENSE.txt`: 글꼴 이용 조건.
