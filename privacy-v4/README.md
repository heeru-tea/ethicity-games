# 프라이버시 보호 · ver4

사용자가 제공한 `시나리오_ver4.html`을 바탕으로 AI 비서의 8가지 생활 사례를 새로 구성한 버전입니다. 기존 `privacy`, `privacy-v2`, `privacy-v3` 및 `harm`은 유지합니다.

## 실행

- 게임: https://ethicity-privacy-20261011.web.app/privacy-v4/
- 교사: https://ethicity-privacy-20261011.web.app/privacy-v4/?mode=teacher
- 혼자 플레이: `index.html` 파일을 브라우저로 엽니다. 이미지와 나눔스퀘어라운드 글꼴이 파일 안에 들어 있어 인터넷 없이 진행합니다.
- 교사는 웹 주소에서 새 수업을 만들고 표시되는 **학생 입장 링크**를 공유합니다. 학생은 닉네임·캐릭터·가상 친구 이름을 정하고 수업에 입장합니다. 학생에게 교사용 주소를 전달하지 않습니다.
- 교사는 `라운드 시작 → 결과 공개 → 다음 라운드` 순서로 진행합니다. 선택 집계와 입장 명단은 각각 별도 창이나 현재 화면에서 확대할 수 있습니다.
- 별도 계정 로그인 화면 없이 이용합니다. 서버가 브라우저의 임시 식별번호를 자동 발급합니다. 수업을 만든 브라우저에서 관리하며, 브라우저 데이터를 지우거나 다른 기기로 바꾸면 기존 수업의 관리 권한을 이어받지 못할 수 있습니다.

## 흐름과 내용

매 라운드는 **사례와 새 장면 그림 → AI 화면 관찰 → 수상한 부분 찾기 → 4가지 보호 방법 → 선택 결과**로 나뉩니다. 대사는 타이핑되며 화면 클릭 또는 Enter/스페이스로 펼칠 수 있습니다. 학습 요소의 번호·이름·설명은 결과에서만 표시합니다.

| 라운드 | 사례 | 정보의 단계 |
|---|---|---|
| 1 | 가입하면 쿠폰을 준대 | 모으기 |
| 2 | 단톡방에서 싸운 일을 AI에게 물어보기 | 쓰기 |
| 3 | 소풍 단체사진 배경 바꾸기 | 모으기 |
| 4 | 단짝이 계정을 같이 쓰자고 해 | 저장·관리 |
| 5 | 스킨을 준다는 새 동의 팝업 | 쓰기·주기 |
| 6 | 공개 계정에 사진 올리기 | 주기 |
| 7 | 종이 울렸는데 태블릿을 반납해야 해 | 저장·관리 |
| 8 | 그만 쓰기로 한 AI 앱 정리하기 | 지우기 |

학생에게 점수를 표시하지 않고 이야기 변화로 피드백합니다. 내부 합계는 낮음 0, 보통 1, 높음 2이며 A는 13~16, B는 8~12, C는 0~7입니다. 어느 엔딩이든 마지막 결과에 도달하면 완료입니다. 다른 게임의 선택은 영향을 주지 않습니다.

원본 시나리오는 `scenario-source.html`, 실제 반영 문서는 `시나리오.html`입니다. 원본의 단체사진 보호 선택에는 학교 이름 가리기를 보완했습니다. 5라운드에 남아 있던 식단 표현은 대화·사진 보정으로 바꿨고, 엔딩 A·C 카드는 40자 이내로 정리했습니다. 나머지 8개 사례·32개 선택의 대사와 판단 기준을 반영했습니다. ‘30일 보관’은 해당 가상 앱의 설정입니다.

## 수정할 파일

- `index.html`: 바로 실행·공유할 완성 파일
- `scenario.json`: 대사, 선택, 결과, 학습 요소, 장면 연결, 엔딩 기준
- `assets/scenes/*.webp`: 새로 생성한 장면 8개
- `assets/image-prompts.json`, `assets/style-prompt.txt`: 이미지 생성에 사용한 문장과 공통 화풍
- `source/*.js`, `source/ver4.css`: 진행·실시간 수업·화면 연출
- `source/rebuild.py`: 문장·코드·이미지 수정 후 단일 HTML을 다시 만드는 도구
- `database.privacy-v4.rules.json`: ver4 서버 규칙 조각. 전체 규칙을 이 파일로 덮어쓰지 않고 기존 규칙에 `roomsV4` 가지를 합칩니다.

`source` 폴더에서 `python rebuild.py`를 실행한 뒤 갱신된 `index.html`을 배포합니다. 선택 점수나 카드 문장을 바꾸면 서버의 엔딩·카드 검증 규칙도 함께 수정합니다.

## 저장과 개인정보

공통 형식은 유지합니다.

```json
{"character":"char_03","nickname":"별고래"}
```

위 값은 `ethicity.player`에, 아래 값은 `ethicity.result.privacy`에 저장합니다.

```json
{"game":"privacy","completed":true,"ending":"A","card":"나와 다른 사람의 정보는 모을 때부터 지울 때까지 보호합니다."}
```

친구 이름·임시 진행·설정은 `ethicity.privacy.v4.*`에 저장합니다. 브라우저 저장이 차단되어도 혼자 게임을 끝까지 진행할 수 있습니다. 교실 서버 경로는 `roomsV4`이며 앞 버전 및 다른 게임과 분리됩니다. 닉네임은 한글 1~5자이며 금지어 목록으로 부적절한 표현을 검사합니다. 모든 우회 표현을 자동으로 완벽히 잡아내는 것은 아니므로 교사가 입장 명단을 확인합니다. 학생에게 실제 이름·학교·연락처를 요구하지 않습니다.

플레이어 저장 ID는 기존과 같은 `char_03`, `char_04`를 유지합니다. 팀 공통 ID가 확정되면 교사용 설정에서 맞출 수 있습니다.

## 그림과 글꼴

플레이어 2종·안내봇·대화용 친구는 처음 제공된 원본 이미지 자료를 유지합니다. 사례 그림 8개는 Imagegen으로 새로 생성했으며 인물·앱·표시는 가상입니다. 글꼴은 파일에 포함된 나눔스퀘어라운드와 시스템 한글 글꼴을 사용합니다. 라이선스는 `NanumSquareRound-LICENSE.txt`에 있습니다.

검증 결과는 `검증결과.json`에 기록합니다. 실시간 수업만 Firebase SDK와 서버 연결이 필요합니다.
