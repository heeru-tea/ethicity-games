# 다양성 2차 피드백 점검 · 2026-11-15

기준: 공동 문서 2차 초등 피드백(다양성 존중), 최신 main 25149bf.

## 이번 보완
- 비교 그림이 나오는 도입 2번째 장에서 바로 왜 비슷한 모습인지 / 다른 모습의 의사도 있을지 질문한다.
- 다음 장에 남성 의사 등장 자체가 잘못은 아니며 여섯 그림으로 모든 AI를 판단할 수 없다는 안내를 명시한다.
- 구현돼 있으나 화면에 연결되지 않았던 세 단계 질문 가이드를 실제 학생 관찰 화면에 연결한다. 같은 점 → 다른 점 → 그림에 나오지 않은 모습 순서이며 수업/학생별 상태를 분리하고 자동 갱신에도 질문 위치를 보존한다.
- 변경 JS/CSS에 내용 해시 캐시 키를 갱신한다.

## 이미 반영된 항목
- OBS01~OBS06 여섯 장, 확대 보기, 검사결과 설명·기록·회진 등 접촉 장면 대체.
- 출석번호 기본값 없음, 1~99 직접 입력 및 확인 안내.
- 교사 큰 다음 단계 버튼, 지금 할 일과 진행 조건, 이전 단계 복귀.
- 학생 상세 토글·입력 포커스·스크롤의 갱신 유지.
- 관찰(공통점/차이점)과 보완 제안 분리, 현재 할 일 안내.

## 승인 보류: 익명 의견 모음
운영 classOpinionsEnabled=false를 유지한다. 이번 변경은 운영 Firebase 규칙·인증·학생 기록을 변경하지 않는다. 별도 검증된 규칙 승인 및 배포 전에는 공유 기능이 완료됐다고 보고하면 안 된다.

후보 설계: 학생의 자발적 공유만 학급에 표시, 본인 의견만 수정, 교사는 공유 사본만 제거하고 개인 기록 유지, 다른 학급/미승인 학생 접근 금지, HTML 텍스트 처리, 500자와 필드/버전 제한. 승인 시 최신 운영 규칙을 기준으로 opinions 경로만 병합하고 기존 구버전·6장 baseline 호환성 및 다른 팀 규칙을 보존해야 한다. 과거 전체 후보 규칙을 그대로 배포하지 않는다.

## 짧은 태블릿 화면 후속 수정
독립 공개 검수에서 1165×747 화면의 발문/다음 버튼이 여섯 그림 아래로 밀린 문제를 확인했다. 발문과 다음 행동을 HTML상 그림 앞에 배치하고 화면 위에 유지한다. 높이 800px 이하 화면은 썸네일 높이/간격을 줄이고, 모바일은 장식 초상을 숨겨 행동 공간을 확보한다.
질문 안내의 공통점/차이점에서 해당 입력칸으로 직접 이동한다. 세 번째 질문은 보완 생각 단계에서 답하는 것임을 명시하며, 관찰 저장 후에만 기존 보완 생각 이동 버튼을 통해 진행한다. 서버 단계나 저장 구조는 바꾸지 않는다.
최종 로컬 DOM·회귀 검사 9/9 통과. 실제 1165×747 공개 브라우저 재검수는 배포 후 별도 담당이 확인한다.
