# 프라이버시 보호 v5 — 윤리시티 공통 자산 적용

기존 `privacy-v4`의 8라운드 대사·선택지·피드백·학습요소·엔딩을 그대로 유지한 새 버전입니다. 기존 버전 폴더는 수정하지 않습니다.

## 실행

- **혼자 탐험:** 이 폴더의 `index.html`을 엽니다. `common`과 `source` 폴더가 같은 위치에 있어야 합니다.
- **실시간 교사 화면:** 웹 서버에 v5 폴더 전체를 올린 뒤 `v5/teacher.html` 또는 `v5/index.html?mode=teacher`를 엽니다. Google 로그인 없이 ‘새 수업 만들기’를 누릅니다.
- **학생 화면:** 교사 화면의 ‘학생 입장 링크 복사’로 받은 주소를 엽니다. 닉네임과 가상 친구 이름을 정한 뒤 ‘수업에 입장합니다’를 누릅니다.
- **확대 화면:** ‘선택 집계 크게 보기’와 ‘입장 명단 크게 보기’로 별도 창을 엽니다. 팝업이 차단되면 현재 화면을 확대합니다. ‘현재 화면 확대’와 ‘화면 가득 보기’도 지원합니다.
- 로컬 파일의 혼자 탐험에는 외부 요청이 없습니다. 실시간 수업에는 인터넷과 기존 Firebase 연결이 필요합니다.

GitHub의 폴더 주소는 소스 열람용입니다. 이번 작업은 GitHub 저장까지이며 기존 Firebase Hosting의 게임 주소는 교체하지 않습니다. 웹에 게시할 때는 `index.html` 한 파일만 올리지 말고 **v5 폴더 전체**를 같은 위치에 올립니다.

## 달라진 점과 유지한 점

| 항목 | v5 |
|---|---|
| 학습 내용 | v4의 8라운드, 각 4개 선택지, 3개 엔딩 유지 |
| 단계 | 사례 → AI 화면 관찰 → 수상한 부분 → 보호 방법 → 결과 |
| 그림 | 공통 팩의 실제 배경·캐릭터·표정·아이콘·효과를 사용 |
| UI | `common/runtime/common.css` 원본을 직접 연결 |
| 글꼴 | 공통 팩의 Galmuri11(Ethicity), 시스템 한글 글꼴 fallback |
| 추가 자료 | 가입, 단체 대화, 사진, 계정, 보상 동의, 공개 범위, 공용 기기, 삭제의 가상 앱 화면 |
| 대화 | 닉네임과 가상 친구 이름을 반영, 타이핑·클릭 전체 표시 유지 |
| 학습요소 | 선택 전에 숨기고 선택 결과에서 번호와 설명 표시 |
| 교사 기능 | 실시간 명단·선택 집계·확대 창·CSV·수업 진행 유지 |

새 그림을 생성하거나 공통 팩의 자산을 편집하지 않았습니다. 사진 사례는 기존 배경과 캐릭터를 조합한 가상 자료입니다. 사례 화면의 문구와 표만 게임 전용으로 추가했습니다.

## 폴더 구분

```text
privacy/            이전 버전 — 변경 없음
privacy-v2/         이전 버전 — 변경 없음
privacy-v3/         이전 버전 — 변경 없음
privacy-v4/         시나리오 원본 — 변경 없음
v5/                 이번 버전
  index.html        학생·혼자 탐험·교사 공용 시작 화면
  teacher.html      교사 화면 바로가기
  scenario.json     v4 시나리오 원본(내용과 원본 버전 표기 유지)
  config.json       기존 공개 Firebase 설정과 저장 캐릭터 ID
  common/           공통 팩 전체의 수정 없는 사본
  source/           진행·실시간 연동·사례 화면·배치 코드
  tests/            검증 코드
  provenance.json   원본 커밋·파일 해시·캐릭터 대응표
  verification.json 자동 검사 결과
  verification-browser.json 실제 브라우저 확인 결과
```

`privacy` 브랜치에 공통 폴더가 없어서, v5가 자체적으로 실행되도록 `main`의 `shared/ethicity-elementary-common-v1`을 `v5/common`에 그대로 포함했습니다. 공통 파일의 내용은 변경하지 않았습니다. 기존 다른 게임 폴더를 수정할 필요가 없습니다.

## 저장과 Firebase 호환

- `ethicity.player` → `{ "character": "char_03", "nickname": "별고래" }` 형식 유지
- `char_03`은 공통 그림 `haneul`, `char_04`는 `jiho`에 연결합니다. 저장 ID와 그림 ID를 분리해 기존 허브와의 호환을 유지합니다.
- 가상 친구의 그림은 `saebom`, 안내봇은 `robot`입니다. 지도와 대화에 같은 ID를 사용합니다.
- 완료 시 `ethicity.result.privacy`에 `game`, `completed`, `ending`, `card`만 저장합니다. 다른 게임 결과는 읽지 않습니다.
- v5의 임시 진행·친구 이름·설정은 `ethicity.privacy.v5.*`에 따로 저장합니다.
- Firebase 인증 앱 이름도 v5 전용으로 구분합니다. 수업마다 임의의 방 ID를 발급합니다.
- 답안·완료 형식이 v4와 같으므로 현재 배포된 **`roomsV4` 데이터 규칙**을 그대로 사용합니다. 규칙을 새로 배포하거나 접근 권한을 넓히지 않았습니다.
- 닉네임과 선택 기록만 기존 수업 서버로 보냅니다. 가상 친구 이름은 기기에만 저장합니다. 실제 개인정보를 넣는 사례 입력칸은 없습니다.
- 비속어 검사는 한글 1~5자 검사와 금지 표현 목록을 사용합니다. 모든 우회 표현을 완벽히 검출하는 기능은 아닙니다.

## 문장 수정

1. 기존 시나리오 문장은 `scenario.json`에서 수정합니다.
2. 새 사례 화면의 내용은 `source/case-data.js`에서 수정합니다.
3. 시나리오 또는 공개 연결 설정을 수정했다면 `python source/build.py`를 실행해 `index.html`에 반영합니다.
4. `common` 폴더는 수정하지 않습니다. `source/v5.css`는 배치와 가상 사례 자료에만 사용합니다.

## 자체 점검

| 점검 | 결과 |
|---|---|
| 파일 구성·외부 요청 | 공통 팩 재사용 요청에 따라 폴더형. 혼자 탐험은 외부 요청 없음, 실시간 수업만 Firebase 사용 |
| 캐릭터·닉네임 저장 | R2 키·객체 형식 유지. 첫 화면에서 설정을 확인하는 후속 요청 반영 |
| 완료 기록·카드 | R3 형식 유지, 40자 이내. 후속 요청에 따라 ‘~니다’ 문체 유지 |
| 라운드·선택지·엔딩 | 후속 요청 기준 8라운드·각 4개·3엔딩 |
| 학습요소·꼬리표 | 기존 ①~⑤ 유지, 모든 선택에 있음, 학생은 결과에서만 확인 |
| 문장과 진행 코드 분리 | scenario.json / case-data.js / 진행 코드 분리 |
| UI·조작 | 공통 UI·글꼴 사용, 클릭·터치·키보드·타이핑 건너뛰기 지원 |
| 개인정보 입력 | 후속 허용된 가상 닉네임·친구 이름만 입력. 실제 사진·학교·연락처 입력과 업로드 없음 |

검사 명령: `node tests/verify.cjs`, `python tests/verify_assets.py`.
