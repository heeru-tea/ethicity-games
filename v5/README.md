# 프라이버시 보호 v5 — 윤리시티 공통 자산 적용

2026년 10월 31일 승인한 시나리오를 반영한 v5입니다. 친구의 가입 → 계정 보호 → 대화 상담 → 사진 보정 → 새 동의 → 사진 공개 → 공용 태블릿 → 계정 정리 이야기가 이어집니다. 각 라운드에 안전한 선택이 두 가지 있으며, 둘 다 최고점으로 인정합니다. 결과 뒤에는 친구와 정리 대화가 이어집니다.

라운드별 상황을 보여 주는 장면 삽화 8장을 추가했습니다. 사례 소개와 결과 화면에 표시하고, AI 화면 관찰 단계에서는 기존의 읽을 수 있는 가상 자료를 확인합니다. 왼쪽 위 제목은 **윤리시티 / 프라이버시 보호**만 표시합니다.

## 바로 실행하기

2026년 10월 31일 승인 시나리오로 v5를 수정했습니다. **기존 다른 버전의 주소와 파일은 그대로 유지했습니다.** 아래 주소는 설치 없이 브라우저에서 열 수 있습니다. 이번 시나리오로 수업할 때는 **새 수업 만들기**로 새 입장 링크를 만듭니다.

| 용도 | 주소 |
|---|---|
| 혼자 해 보거나 수업 전에 미리 보기 | [v5 게임 실행](https://ethicity-privacy-20261011.web.app/v5/) |
| 수업을 만들고 학생들의 선택 확인하기 | [v5 교사용 화면](https://ethicity-privacy-20261011.web.app/v5/teacher.html) |

**함께하는 수업의 학생 입장 주소는 수업을 만들 때마다 달라집니다.** 학생에게는 아래 절차로 복사한 **학생 입장 링크**를 보내 주세요. 위의 일반 게임 주소로 열면 혼자 탐험을 시작하므로 교사 화면에 연결되지 않습니다.

## 교사: 수업 만들고 학생 초대하기

1. [v5 교사용 화면](https://ethicity-privacy-20261011.web.app/v5/teacher.html)을 엽니다. 별도 회원가입이나 Google 로그인은 필요하지 않습니다.
2. 화면 위에 **연결됨**이 표시되면 **새 수업 만들기**를 누릅니다.
3. **학생 입장 링크 복사**를 눌러 학급 게시판이나 메신저 등 평소 사용하는 방법으로 학생들에게 주소를 공유합니다. 복사가 안 되면 화면에 보이는 입장 주소를 직접 선택해 복사합니다.
4. 학생들이 입장을 마치면 **입장 명단**에 닉네임이 실시간으로 나타납니다. 이름과 입장 인원을 확인합니다.
5. 준비가 끝나면 **1라운드 시작하기**를 누릅니다. 필요하면 **새 입장 마감하기**로 추가 입장을 막을 수 있습니다. 늦게 온 학생이 있으면 **새 입장 열기**를 누릅니다.

## 학생: 선생님 수업에 입장하기

1. **선생님이 보내 준 학생 입장 링크**를 엽니다.
2. 캐릭터를 고르고, 자신의 닉네임과 이야기 속 가상 친구 이름을 입력합니다. 각각 **한글 1~5자**로 정하며 실제 이름·학교·연락처는 쓰지 않습니다.
3. **이 탐험가로 출발합니다 →**를 누르고 친구와의 도입 대화를 읽습니다. 글자가 나오는 중에는 말풍선이나 화면을 눌러 문장을 한꺼번에 볼 수 있습니다.
4. **수업에 입장합니다 →**를 누릅니다. “친구들이 모이고 있습니다”라는 대기 화면이 나오면 입장이 끝난 것입니다. 선생님이 라운드를 열 때까지 기다립니다.

닉네임만 입력한 상태에서는 입장 명단에 표시되지 않습니다. **수업에 입장합니다 →**까지 눌렀는지 확인해 주세요.

## 수업 진행과 마무리

1. 학생은 **사례 → AI 화면 관찰 → 수상한 부분 찾기 → 보호 방법 선택** 순서로 진행합니다. 선택을 제출하면 선생님의 결과 공개를 기다립니다.
2. 교사는 **이번 라운드 응답** 인원과 선택 집계를 확인한 뒤 **응답 마감 · 결과 공개**를 누릅니다. 학생들은 선택 결과와 학습요소를 확인합니다.
3. 함께 이야기한 뒤 **다음 라운드 열기 →**를 누릅니다. 같은 방법으로 총 8라운드를 진행합니다.
4. 마지막 라운드의 결과를 공개한 뒤 **수업 마무리 · 남은 사례 열기**를 누릅니다. 놓친 사례가 있는 학생은 이어서 완료할 수 있습니다. 엔딩 화면까지 도달하면 완료 기록이 남습니다.
5. 필요한 경우 **기록 CSV 내려받기**로 닉네임·라운드별 선택·완료 여부를 파일로 보관합니다. 내려받은 CSV는 엑셀 등에서 열 수 있습니다.

### 수업 중 편리한 기능

- **선택 집계 크게 보기 / 입장 명단 크게 보기:** 해당 내용을 별도 창에서 크게 봅니다. 별도 창이 열리지 않으면 **현재 화면 확대**를 이용합니다.
- **화면 가득 보기:** 교실 화면에 크게 띄울 때 사용합니다.
- 명단은 **한 번 입장한 학생의 기록**입니다. 이름이 남아 있다고 해서 지금도 화면을 열어 두고 있다는 뜻은 아닙니다.

### 연결이 안 되거나 다음 수업을 열 때

- 교사와 학생 모두 인터넷이 연결되어 있어야 합니다. “재연결 중”이면 인터넷을 확인하고 화면을 닫지 않은 채 잠시 기다립니다.
- 학생이 입장되지 않으면 **해당 수업의 입장 링크**인지, 교사가 **새 입장 열기**로 입장을 허용했는지 확인합니다.
- 이전 수업을 다시 열려면 **수업을 만들었던 기기와 브라우저**에서 같은 교사용 주소를 엽니다. 목록에서 **수업 열기**를 누릅니다.
- 비공개·시크릿 창을 닫거나 브라우저의 사이트 저장정보를 지우면 이전 수업을 다시 조작할 수 없습니다. 일반 창을 사용하고 필요한 기록은 CSV로 보관합니다.

## 파일로 혼자 실행하기

이 폴더의 `index.html`을 엽니다. **`common`과 `source` 폴더가 같은 위치에 있어야 합니다.** 로컬 파일의 혼자 탐험에는 외부 요청이 없으며 인터넷 없이 진행할 수 있습니다. 실시간 수업은 위의 배포된 웹 주소에서 엽니다.

GitHub의 폴더 주소는 소스 열람용입니다. 다른 웹 서버에 옮길 때는 `index.html` 한 파일만 올리지 말고 **v5 폴더 전체**를 같은 위치에 올립니다.

## 달라진 점과 유지한 점

| 항목 | v5 |
|---|---|
| 학습 내용 | 승인한 연결 시나리오 8라운드, 각 4개 선택지·안전한 방법 2개, 3개 엔딩 |
| 단계 | 사례 → AI 화면 관찰 → 수상한 부분 → 보호 방법 → 결과 |
| 그림 | 공통 팩의 실제 배경·캐릭터·표정·아이콘·효과를 사용 |

| 글꼴 | 공통 팩의 Galmuri11(Ethicity), 시스템 한글 글꼴 fallback |
| 추가 자료 | 가입, 단체 대화, 사진, 계정, 보상 동의, 공개 범위, 공용 기기, 삭제의 가상 앱 화면 |
| 대화 | 닉네임과 가상 친구 이름을 반영, 타이핑·클릭 전체 표시 유지 |
| 학습요소 | 선택 전에 숨기고 선택 결과에서 번호와 설명 표시 |
| 교사 기능 | 실시간 명단·선택 집계·확대 창·CSV·수업 진행 유지 |

공통 팩의 자산은 편집하지 않았습니다. 사용자의 장면 이미지 추가 요청에 따라 공통 팩에 없는 사건 삽화 8장을 `assets/scenes`에 생성했습니다. 공식 도서관 배경과 세계관 레퍼런스의 색감·도트 질감을 참고했습니다. 사진 속 인물은 기존 공통 캐릭터 원본을 겹쳐 표시합니다. 학습에 필요한 정확한 문구와 설정은 기존 관찰 화면에서 읽습니다.

## 저장과 Firebase 호환

- `ethicity.player` → `{ "character": "char_03", "nickname": "별고래" }` 형식 유지
- `char_03`은 공통 그림 `haneul`, `char_04`는 `jiho`에 연결합니다. 저장 ID와 그림 ID를 분리해 기존 허브와의 호환을 유지합니다.
- 가상 친구의 그림은 `saebom`, 안내봇은 `robot`입니다. 지도와 대화에 같은 ID를 사용합니다.
- 완료 시 `ethicity.result.privacy`에 `game`, `completed`, `ending`, `card`만 저장합니다. 다른 게임 결과는 읽지 않습니다.
- 새 시나리오의 임시 답안은 `ethicity.privacy.v5.story20261031.draft.*`에 저장해 이전 답안을 잘못 이어 읽지 않습니다. 캐릭터와 닉네임은 기존 형식을 유지합니다.
- Firebase 인증 앱 이름도 v5 전용으로 구분합니다. 수업마다 임의의 방 ID를 발급합니다.
- 새 수업은 **`roomsPrivacyV5Story20261031`**에 저장합니다. 이전 기록과 답안 번호·평가가 섞이지 않도록 구분합니다. 기존 소유자·학생별 접근 제한을 유지하며, 새 점수·카드만 검증합니다. `database.v5.rules.json`은 추가할 규칙 조각이며 기존 전체 규칙을 이 파일로 덮어쓰면 안 됩니다.
- 이번 수정 후에는 **새 수업 만들기**로 만든 새 학생 입장 링크를 공유해 주세요. 이전 시나리오 수업 기록은 삭제하지 않았습니다. 이전 실행 파일은 GitHub 변경 이력에서 확인할 수 있습니다.
- 닉네임과 선택 기록만 기존 수업 서버로 보냅니다. 가상 친구 이름은 기기에만 저장합니다. 실제 개인정보를 넣는 사례 입력칸은 없습니다.
- 비속어 검사는 한글 1~5자 검사와 금지 표현 목록을 사용합니다. 모든 우회 표현을 완벽히 검출하는 기능은 아닙니다.

## 문장 수정

1. 기존 시나리오 문장은 `scenario.json`에서 수정합니다.
2. 새 사례 화면의 내용은 `source/case-data.js`에서 수정합니다.
3. 시나리오 또는 공개 연결 설정을 수정했다면 `python source/build.py`를 실행해 `index.html`에 반영합니다.
4. 선택지 순서는 라운드별로 섞어 저장합니다. 같은 수업의 교사와 학생은 동일한 순서를 봅니다. 점수나 카드 문장을 바꿀 때는 서버 검증 규칙도 함께 갱신합니다.
5. `common` 폴더는 수정하지 않습니다. `source/v5.css`는 배치와 가상 사례 자료에만 사용합니다.
