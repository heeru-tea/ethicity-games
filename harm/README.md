# 침해금지 — 윤리시티 얼굴·목소리 지킴대

초등학교 5~6학년이 함께 참여하는 **교사 컨트롤타워형 AI 윤리 게임**입니다. 게임 코드는 `harm`입니다. 다온과 모아의 얼굴·목소리 관련 오해를 함께 해결하고, 마지막에는 도담에게 생길 수 있는 새로운 위험을 살펴봅니다.

## 다운로드 없이 바로 실행

- **[교사 컨트롤타워 열기](https://ethicity-privacy-20261011.web.app/harm/?mode=teacher)**
- **[게임 시작 화면 열기](https://ethicity-privacy-20261011.web.app/harm/)**
- [전체 시나리오 읽기](https://ethicity-privacy-20261011.web.app/harm/%EC%8B%9C%EB%82%98%EB%A6%AC%EC%98%A4.html)

교사는 위 주소에서 **새 수업 만들기 → 학생 입장 링크 복사**를 누릅니다. 학생에게는 복사한 수업 링크를 전달합니다. 실시간 수업을 할 때는 교사와 학생 모두 인터넷이 연결되어 있어야 합니다.

## 실행 파일

- **[index.html](index.html)**: 실행에 필요한 그림·글꼴·스타일·시나리오·코드가 들어 있는 파일 하나입니다.
- **[시나리오.html](시나리오.html)**: 교사가 읽을 수 있는 전체 시나리오, 선택지별 학습 요소, 엔딩 기준입니다.
- **[scenario.json](scenario.json)**: 나중에 대사와 상황을 고칠 때 사용하는 원본입니다.
- **[database.harm.rules.json](database.harm.rules.json)**: `harm`의 실시간 수업 접근 제한 규칙입니다. 기존 게임의 전체 규칙을 대체하는 파일이 아닙니다.

GitHub의 파일 화면은 코드를 보관하는 화면입니다. `index.html`은 그림과 글꼴을 포함해 약 10.9MB이므로 GitHub에서 큰 파일을 표시할 수 없다는 안내가 나올 수 있습니다. 게임은 위의 **바로 실행 주소**에서 엽니다. 내려받은 파일을 직접 여는 경우에는 **이 기기에서 수업 미리보기**만 사용할 수 있으며, 교사·학생 실시간 연결은 웹 주소에서 사용합니다.

## 라운드별 장면 그림

8개 라운드마다 3문단의 줄거리와 장면 그림을 함께 보여 줍니다. 같은 라운드의 투표·동률·응답 없음·결과 화면에서도 이야기가 계속 표시됩니다. 시나리오 문서에서도 줄거리와 그림을 확인할 수 있습니다.

1. 다온의 얼굴이 담긴 가짜 영상
2. 원본과 퍼진 영상 비교
3. 취소 전화를 받은 모아와 약속 장소에서 기다리는 다온
4. 놀이 영상에 따로 덧붙인 AI 더빙
5. 여러 게시판으로 퍼진 같은 영상
6. 확인한 사실을 정리하고 설명하는 자리
7. 다온과 모아의 이야기를 듣는 친구
8. 새 동아리 소개 영상을 만들기 전의 선택

내장 이미지 생성 도구(`image_gen`)로 제작한 가상 장면입니다. 그림은 상황 이해를 돕는 삽화이며, 원본 영상이나 실제 증거 자료가 아닙니다. 정확한 대사·단서·선택지는 그림 아래의 글자로 읽습니다. [장면 이미지](assets/scenes/)와 [제작 프롬프트·장면 설명](source/scene-images.json)을 함께 보관합니다. 그림은 실행 파일 안에 포함되어 별도 이미지 요청 없이 표시됩니다.

## 수업 진행

1. 교사는 웹 주소로 게임을 열고 **교사 컨트롤타워**를 선택합니다. 별도 이름·이메일·비밀번호 입력 없이 이 브라우저의 수업 열쇠를 만듭니다.
2. **새 수업 만들기 → 학생 입장 링크 복사**로 주소를 준비해 학생에게 공유합니다.
3. 학생은 링크를 열어 캐릭터와 가상 닉네임을 정하고 입장합니다. 같은 웹 주소에 `ethicity.player`가 이미 있으면 캐릭터 선택을 건너뛰고 도입으로 갑니다.
4. 명단을 확인한 교사가 **도입 시작**을 누릅니다. 이후에는 새 학생 입장이 닫힙니다. 이미 입장했던 학생은 같은 브라우저로 다시 연결할 수 있습니다.
5. 도입과 이야기는 시간 제한 없이 읽습니다. 교사는 **첫 번째 이야기 읽기 → 20·40·60·90초 중 투표 시작 → 결과 읽기 → 다음 이야기 읽기** 순서로 진행합니다. 투표 시간은 교사 진행 영역에서만 표시됩니다. 투표 중에는 **투표 일시정지 / 투표 계속하기 / +15초 / 투표 마감 · 결과 보기**로 조정합니다. 일시정지 중에도 바로 마감할 수 있습니다.
6. 학생은 마감 전까지 자기 표를 바꿀 수 있습니다. 학생 화면에는 마감 전 학급 집계를 보이지 않습니다. 동률이면 교사가 동률인 선택 중에서 정합니다. 응답이 0표이면 임의의 결과를 내지 않고 다시 투표합니다.
7. 8라운드가 끝나면 모두에게 같은 엔딩이 표시됩니다. 교사가 학급 의견을 들으며 정리 문장을 고르면 학생 화면에도 같은 답이 나타납니다.

**전체 수업 시간은 교사의 읽기·토론 진행에 따라 달라집니다.** 도입·이야기·결과·정리는 시간이 지나도 자동으로 넘어가지 않습니다. 투표만 선택한 시간이 끝나면 집계되며, 결과를 읽은 뒤 교사가 다음 이야기를 엽니다. 학생은 투표가 끝나도 같은 줄거리를 계속 읽을 수 있습니다. 투표 자동 마감을 위해 교사 화면을 열어 둡니다. 연결이 끊어지면 다시 연결한 뒤 시간과 응답을 확인합니다.

같은 기기의 탭들은 같은 학생으로 인식할 수 있습니다. 실제 수업에서는 학생마다 자기 기기 또는 독립된 브라우저 환경을 사용합니다. 교사의 수업 열쇠도 같은 브라우저·웹 주소에 있으므로 수업 중에는 브라우저 저장 자료를 지우지 않습니다.

## 세 가지 공동 엔딩

| 엔딩 | 판정 기준 |
|---|---|
| A · 친구를 돕고 새 위험도 막았습니다 | 1~4라운드 보호 선택 3회 이상, 5~7라운드 보호 선택 2회 이상, 8라운드 보호 선택 |
| B · 오해를 풀고 배움을 이어갑니다 | 5~7라운드 보호 선택 2회 이상이며 A 조건에는 해당하지 않음 |
| C · 함께 돕는 행동이 더 필요합니다 | 5~7라운드 보호 선택 0~1회 |

세 엔딩 모두 완료입니다. 각 라운드의 학급 다수결 결과를 사용하며, 개인 점수로 엔딩을 나누지 않습니다. `시나리오.html`에서 각 보호 선택과 결과 설명을 볼 수 있습니다.

## 팀 공통 저장

학생의 기기에 다음 두 값만 공통 형식으로 저장합니다. 이외의 수업용 상태는 `harm` 전용 이름을 사용합니다.

```json
// localStorage 키: ethicity.player
{"character":"char_03","nickname":"별고래"}
```

```json
// localStorage 키: ethicity.result.harm
{"game":"harm","completed":true,"ending":"A","card":"위험 신호를 살피고 함께 확산을 막습니다."}
```

카드는 40자 이내의 한 문장이며 `~합니다` 문체입니다. 저장이 차단되어도 게임은 끝까지 진행되며, 화면에 완료 기록을 보관하지 못했다는 안내가 표시됩니다. 교사 기기에는 학생 배지를 저장하지 않습니다. 교사 명단의 완료 확인은 수업 서버가 받은 완료 기록이며, 학생 기기의 실제 저장 성공 여부는 해당 학생 화면에서 확인합니다.

**허브와 게임은 같은 웹 주소의 출처(프로토콜·호스트·포트)를 사용해야 localStorage를 함께 읽을 수 있습니다.** 다른 도메인에 올리면 같은 기기라도 저장값을 공유하지 않습니다. 파일을 직접 연 경우의 저장 방식은 브라우저마다 다를 수 있습니다.

## 개인정보와 접근 범위

- 요청에 따라 닉네임만 자유 입력합니다. 새 닉네임은 완성된 한글 1~5자로 제한하고 실제 이름·학교·연락처를 적지 않도록 안내합니다. 공통 저장에 있던 캐릭터·조합 닉네임은 그대로 재사용합니다.
- 모든 인물·대화·게시물·통화 장면은 가상입니다. 사진·음성 업로드, 실제 통화, AI 합성 기능은 없습니다.
- 선택지에는 학습 요소 번호를 표시하지 않습니다. 모든 선택지의 번호는 시나리오 데이터에 남기며 결과 설명에서 학습 요소를 확인합니다.
- 기존 레퍼런스와 같은 Firebase 프로젝트 및 SDK를 사용합니다. 코드에 들어 있는 Firebase 설정은 공개용 웹 설정입니다. 비밀번호·서비스 계정 키·개인 API 키는 포함하지 않습니다.
- 서버의 `roomsHarm` 아래에 별도의 수업을 만듭니다. 교사는 자신이 만든 방만 읽고 진행합니다. 학생은 자신의 닉네임·표·완료 기록과 학급의 공개 결과만 접근합니다. 다른 학생의 이름과 투표는 읽을 수 없습니다.
- 투표 마감·일시정지·현재 라운드·선택 범위를 서버에서도 검사합니다. 학생은 교사 진행 상태나 공동 엔딩을 바꿀 수 없습니다.

## 시나리오를 나중에 수정하는 방법

**수정할 수 있습니다.** `scenario.json`의 대사, 상황, 단서, 선택지와 피드백을 고친 뒤 다음 명령으로 실행 파일과 시나리오 문서를 다시 만듭니다. 교사는 수정할 문장을 알려 주면 되고, 아래 작업은 개발 담당자가 해도 됩니다.

```powershell
python harm/source/build.py
python harm/source/build_rules.py
node harm/source/verify.cjs
```

명령은 저장소의 맨 위 폴더에서 실행합니다. 빌드는 같은 저장소의 `privacy-v3/index.html`에서 공통 그림·글꼴·캐릭터를 가져옵니다. 완성된 `harm/index.html`은 그 파일에 의존하지 않고 혼자 실행됩니다.

현재 버전은 `harm-2026-10-18-v2`입니다. 변경된 진행 방식을 사용하려면 교사·학생 모두 새로고침하고 새 수업을 만듭니다. 이미 열어 둔 이전 버전 수업은 이전 파일로 마칠 수 있도록 서버 규칙에서 기존 버전 값을 유지합니다. 수업 내용을 변경하면 `version`도 새 값으로 바꾸고, 새 파일로 새 수업을 만듭니다. 보호 선택의 위치·엔딩·카드·버전이 바뀌면 서버 규칙도 다시 생성해 적용해야 합니다. 수업 도중에는 파일이나 판정 기준을 바꾸지 않습니다.

`database.harm.rules.json`은 **규칙 조각**입니다. 현재 서버 규칙을 백업하고 `rules.roomsHarm` 항목만 병합해 적용합니다. 이 파일 전체로 기존 규칙을 덮어쓰면 다른 편이 작동하지 않을 수 있습니다. 2026-10-18 구현 시에는 기존 규칙을 보존한 채 `roomsHarm`만 추가했고, 실제 서버와 일치함을 확인했습니다.

## 구현 검사

- 판정·저장·데이터 검사 9개 통과. 8라운드의 선택 조합 6,561개 전체 검사.
- 실제 Firebase 검사 53개 통과. 교사가 고른 투표 시간, 시간 초과 후 제출 차단, 시간 연장, 세 엔딩, 투표 수정, 동률, 접근 제한, 공동 결과 저장 확인. 일회용 시험 자료 정리 완료. 자세한 결과는 [verification-live.json](verification-live.json).
- 브라우저에서 캐릭터 선택, 저장된 캐릭터 재사용, 8라운드 미리보기, 정리 문장 선택, 기기 완료 저장, 한 줄 카드 이미지 내려받기 확인.
- 실제 교사·학생 화면을 따로 열어 8라운드 투표, 공동 엔딩, 기기·서버 완료 확인, 정리 문장의 동기화를 확인.

글꼴은 레퍼런스와 같은 나눔스퀘어라운드입니다. 이용 조건은 실행 파일 안과 [NanumSquareRound-LICENSE.txt](NanumSquareRound-LICENSE.txt)에 포함되어 있습니다.
