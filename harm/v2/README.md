# 윤리시티 얼굴·목소리 지킴대 ver2

초등학교 5~6학년을 위한 침해금지 학급 공동 선택 게임입니다. 기존 `harm`의 8라운드 시나리오와 교사·학생 실시간 투표를 유지하고, 윤리시티 공통 팩 1.0.0의 화면과 캐릭터를 적용했습니다. 기존 버전은 상위 `harm/`에 그대로 있습니다.

## 바로 실행

- [게임 시작 화면](https://ethicity-privacy-20261011.web.app/harm/v2/)
- [교사 컨트롤타워](https://ethicity-privacy-20261011.web.app/harm/v2/?mode=teacher)
- [시나리오 문서](https://ethicity-privacy-20261011.web.app/harm/시나리오.html)

교사가 **새 수업 만들기 → 학생 입장 링크 복사**를 누릅니다. 학생은 복사한 링크로 입장합니다. ver2에서 생성한 입장 링크는 ver2 화면을 엽니다. 실시간 수업은 인터넷이 연결된 웹 주소에서 사용합니다.

## 달라진 화면

- `shared/ethicity-elementary-common-v1/manifest.json`에 있는 캐릭터·배경·아이콘·피드백 효과·효과음을 사용합니다. 공통 폴더는 수정하지 않았습니다.
- 공통 `runtime/common.css`의 색상·글꼴·버튼·패널·말풍선을 사용합니다. 별도 CSS는 게임에 필요한 배치와 반응형 화면을 담당합니다.
- 시작은 공통 중앙마당, 도입은 공통 교실입니다. 지도와 대화의 다온은 모두 `daon`입니다.
- 사건 삽화 8개의 다온을 공통 팩의 여자 캐릭터 외형(갈색 낮은 양 갈래 머리, 주황 머리핀, 보라색 후드와 가방)에 맞췄습니다. 영상·사진 속 작은 다온도 함께 수정했습니다. 수정한 삽화는 `assets/scenes/`에 있으며 v1 그림은 그대로 보존합니다.
- 타이핑 효과를 유지합니다. 클릭 반짝임은 공통 `clue`, 결과 효과는 `correct`·`retry`를 사용합니다. **배경음악 재생 기능과 버튼·음량 조절은 제거했습니다.**
- 클릭·결과 효과음은 **화면·소리**에서 켜고 끕니다. 기본적으로 꺼져 있으며, 이전 설정을 저장한 기기에서는 선택한 효과음 설정을 이어 씁니다.

## 유지한 수업 규칙

시나리오 원본은 상위 `harm/scenario.json` 한곳입니다. 라운드 순서·대사·선택지·학습 꼬리표·엔딩 판정은 변경하지 않았습니다. v2를 만들 때 1라운드의 외형 설명만 “초록 모자를 쓴 다온”에서 “보라색 후드를 입은 다온”으로 맞춥니다. 이 보정은 `source/scene-images.json`에 기록되어 있습니다.

- 이야기와 결과는 교사가 다음 단계를 열 때까지 계속 표시합니다.
- 투표 시간은 교사가 20·40·60·90초 중 선택합니다. 일시정지·15초 추가·직접 마감이 가능합니다.
- 학생은 마감 전에 선택을 바꿀 수 있습니다. 학생 화면에서는 마감 전에 학급 집계를 공개하지 않습니다.
- 동률은 교사가 결정하고, 0표이면 다시 투표합니다.
- 8라운드의 학급 선택으로 A·B·C 중 하나의 공동 엔딩이 결정됩니다. 모든 엔딩을 완료로 저장합니다.
- 닉네임은 기존 요청대로 한글 1~5자 자유 입력입니다. 선택지에는 학습 번호를 표시하지 않으며 데이터에는 유지합니다. 한 줄 카드는 40자 이내의 합니다 문체입니다.

## 허브·기존 수업과의 호환

저장 키와 값 구조, 서버 경로, 시나리오 버전은 기존 게임과 같습니다. 화면 변경만으로 수업 접근 규칙을 변경하지 않습니다.

```json
// ethicity.player
{"character":"char_03","nickname":"별고래"}
```

```json
// ethicity.result.harm
{"game":"harm","completed":true,"ending":"A","card":"위험 신호를 살피고 함께 확산을 막습니다."}
```

| 저장 ID | 표시하는 공통 캐릭터 |
|---|---|
| `char_03` | `haneul` · 하늘 |
| `char_04` | `jiho` · 지호 |

저장된 캐릭터가 있으면 선택 화면을 건너뜁니다. 캐릭터 저장에 공통 팩의 새 ID를 직접 쓰지 않으므로 기존 허브와 서버가 계속 읽을 수 있습니다. 완료 저장이 차단되어도 게임은 끝까지 진행됩니다. 교사 기기에 학생 완료 배지를 저장하지 않습니다.

## 파일과 수정 방법

- `index.html`: 공통 이미지·글꼴·효과음·시나리오·코드를 포함한 실행 파일 하나입니다. GitHub의 파일 미리보기 크기 제한이 있으므로 위의 실행 주소를 사용합니다.
- `source/build.py`: 원본 공통 팩과 수정한 사건 이미지를 내장합니다. 빌드 과정에서 그림을 생성하거나 변형하지 않습니다.
- `assets/scenes/`: 다온 외형을 수정한 사건 삽화 8개입니다.
- `source/scene-images.json`: 장면 설명, 실제 편집 프롬프트, 원본 장면·공통 다온 참조 경로, 파일 크기와 외형 설명 보정입니다. 내장 이미지 편집 도구로 수정한 뒤 구도·해상도를 바꾸지 않고 WebP로 저장했습니다.
- `source/game.js`: 화면과 기존 학급 진행 로직입니다.
- `source/common-ui.js`: 공통 캐릭터 표시, 아이콘, 클릭 효과와 효과음을 연결합니다.
- `source/experience.js`: 대사 타이핑과 공통 클릭 반짝임, 화면·효과음 설정입니다.
- `source/layout.css`: 게임 화면 배치와 작은 화면 대응입니다.
- `build-info.json`: 공통 팩·사건 이미지의 원본 해시와 빌드 정보입니다.

저장소 루트에서 다음 명령을 실행합니다.

```powershell
python harm/v2/source/build.py
node harm/v2/source/verify.cjs
node harm/v2/source/verify-experience.cjs
```

브라우저 검사는 Playwright와 Edge를 사용하는 개발용 검사입니다. 게임 실행에는 필요하지 않습니다. `source/verify-browser.cjs`는 임시 로컬 서버를 직접 열고 검사 후 닫습니다. `HARM_TEST_URL`을 지정하면 해당 웹 주소를 검사합니다.

내려받은 `index.html` 파일에서는 인터넷 없이 **이 기기에서 수업 미리보기**를 사용할 수 있습니다. 교사·학생 실시간 수업은 웹 주소에서 실행합니다.

| 공통 팩 원본 캐릭터·배경·소품·아이콘·효과음 | 내장한 파일 바이트가 원본과 일치 |
| 공통 UI와 런타임 | 공통 CSS는 파일 주소 내장 외 변경 없음, 공통 JS 동일 |

| 학습 요소와 선택지 | ①~⑤ 모두 포함, 모든 선택지에 데이터 꼬리표 유지 |

| 저장과 카드 | 기존 키·구조 유지, 모든 엔딩 완료, 카드 40자 이내 합니다 문체 |

| 시험 자료 | 최초 v2 배포 시험 수업과 익명 계정 삭제 완료 |

2026-10-25 수정본에서 판정·자산·호환 검사 11개, 타이핑·배경음악 제거 검사 5개, 브라우저 시나리오 검사 6개를 통과했습니다. 세부 기록은 `verification.json`, `verification-browser.json`에 있습니다. `verification-classroom.json`은 최초 v2 배포 때 통과한 실시간 학급 검사 3개의 기록입니다. 실명·사진·음성 업로드와 비밀 키를 추가하지 않았으며, 닉네임 자유 입력은 교사의 변경 요청을 유지했습니다.
