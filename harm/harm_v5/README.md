# 매직메이커AI 공방 · harm v5

v4에서 이야기 속 친구 이름이 모두 ‘학생’으로 표시되고 선택지 글씨가 작던 문제를 수정했습니다. 온유·새봄·다온의 이름을 이야기, 분기, 대사, 결과와 개인 리포트에 복원하고, 선택 화면에 승인된 상황 이해 그림 8장을 넣었습니다.

- [교사 컨트롤타워](https://ethicity-privacy-20261011.web.app/harm/harm_v5/?mode=teacher)
- [게임 시작·미리보기](https://ethicity-privacy-20261011.web.app/harm/harm_v5/)

교사는 새 수업을 만든 후 화면의 QR·학생 입장 링크를 공유합니다. 학생은 A/B버전 탐험가를 골라 입장합니다. 실제 이름 입력은 없습니다. 온유·새봄·다온은 이야기 속 가상 인물입니다. 기존 v4와 공통 팩은 수정하지 않았습니다.

## 이번 변경

- 선택지: 큰 화면 22~24px, 태블릿 20px, 작은 휴대폰 18px. 줄 간격과 여백을 늘리고 긴 문장을 자르지 않습니다. 공간이 부족하면 선택 영역 또는 페이지를 스크롤합니다.
- 선택 화면 왼쪽에는 라운드별 그림·설명과 기존 캐릭터·이름, 오른쪽에는 선택지를 표시합니다. 세로 화면에서는 그림 아래에 선택지가 놓입니다.
- 3라운드 그림은 ‘사진을 보낸다면’이라는 가능성을 설명합니다. 공유를 막은 분기에 실제 피해가 있었다고 덧붙이지 않습니다.
- 그림은 사용자 승인 후 원본 PNG와 모든 픽셀이 같은 무손실 WebP로 변환했습니다. assets/choice-illustrations.json에 생성·수정 프롬프트와 해시가 있습니다.
- 공통 캐릭터·배경·버튼·글꼴·효과음과 사용자 제공 Pixel Adventure 음악은 유지합니다.

## 수업과 저장

8라운드, 교사의 수동 진행, 시간 제한 없는 투표, 다수결, 동률 시 교사 결정, 3개 엔딩, 개인 PNG 리포트는 v4와 같습니다. 서버 공간은 roomsHarmV5, 시나리오는 harm-2026-11-05-v5로 구분합니다.

- 캐릭터 저장 키: ethicity.player
- 완료 저장 키: ethicity.result.harm
- 완료 형식: {"game":"harm","completed":true,"ending":"A|B|C","card":"엔딩 카드 문장"}
- 모든 엔딩을 학생 기기에 완료로 저장하며, 저장소가 막혀도 게임을 진행합니다.
- 교사·학생은 같은 버전의 수업별 입장 링크를 사용합니다. 교사는 주소의 teacherRoom을 유지한 채 같은 브라우저에서 새로고침하면 수업을 복구합니다.
- index.html에는 그림·글꼴·음악이 내장되어 있어 파일만으로 미리보기가 가능합니다. 실시간 수업에는 인터넷 연결이 필요합니다.

## 점검과 재배포

저장소 루트에서 실행합니다.

```text
python harm/harm_v5/source/build.py
python harm/harm_v5/source/build_rules.py
node harm/harm_v5/source/verify-rules.cjs
node harm/harm_v5/source/verify-content.cjs
```

규칙·상태 검사는 수동 진행, 미응답·재투표·동률, 확정 결과 보호, 자기 투표 권한, 모든 6,561가지 선택 경로를 확인합니다. 내용 검사는 v4와의 점수·엔딩·완료 형식 일치, 이름 복원, 승인 그림과 공통 자산 보존을 확인합니다. 브라우저 측정과 운영 검사는 verification-*.json의 실제 기록을 참고하세요. v4의 Playwright 검사 스크립트도 보관하되, 실행하지 않은 검사를 완료했다고 표시하지 않습니다.

서버 규칙은 기존 전체 규칙에 roomsHarmV5만 병합합니다. Hosting은 기존 운영 파일·설정을 복제하고 /harm/harm_v5/index.html 하나만 추가하거나 갱신합니다. 이 폴더만을 전체 사이트로 배포하거나 규칙 조각으로 전체 규칙을 덮어쓰지 마세요. 배포 기록은 deployment.json, 빌드 해시는 build-info.json에 있습니다.

실제 iPadOS·Android 기기 검사는 별도입니다. 화면 크기별 검사는 데스크톱 브라우저에서 수행합니다.
