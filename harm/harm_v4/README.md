# 매직메이커AI 공방 · harm v4

`harm` 브랜치의 `harm/harm_v3`를 바탕으로 만든 초등 AI 윤리 수업 게임입니다. 기존 v3 파일은 변경하지 않습니다.

## 사용

`index.html`을 열고 **수업 미리보기**로 기기 한 대에서 실행할 수 있습니다. 그림, 글꼴, 음악, QR 생성 코드까지 내장하므로 미리보기에는 인터넷이 필요하지 않습니다.

실시간 수업에서는 배포된 v4 주소의 `?mode=teacher`로 교사 화면을 엽니다. **새 수업 만들기** 직후 QR코드와 학생 입장 링크가 나타납니다. 진행 중에도 **입장 QR·링크** 버튼으로 다시 표시합니다. 수업 목록은 따로 조회하거나 보관하지 않습니다. 진행 중인 교사는 주소에 포함된 `teacherRoom`을 유지하고 같은 기기·브라우저에서 새로고침하면 수업을 복구합니다.

학생은 **A버전 탐험가 / B버전 탐험가** 중 하나를 고릅니다. 별도의 이름 입력은 없습니다. 교사는 입장 순서 번호로 참여자를 구분하며, 투표는 각 기기의 익명 인증 ID로 구분합니다. 이야기 속 학생의 표시는 모두 **학생**, 가족은 **할머니**로 통일했습니다.

## 수업 흐름

1. **화면 보기**: 교사가 이야기, 대사, 키오스크 화면을 한 장면씩 넘깁니다. 대사는 한 개만 표시하고, 현재까지 등장한 인물이 큰 게임 화면에 추가됩니다.
2. **단서 확인**: 단서를 하나씩 짚습니다. 선택지는 아직 열리지 않습니다.
3. **선택**: 학생이 제출합니다. 마감 전에는 바꿔 제출할 수 있습니다. 시간 제한, 자동 진행, 일시정지·시간 추가 기능은 없습니다.
4. **결과**: 교사가 직접 마감합니다. 동률이면 최다 득표 선택 중 교사가 결정하고, 0표이면 다시 엽니다. 선택에 따른 반응과 결과도 하나씩 확인합니다.

교사의 **선택별 해설**은 현재까지의 학급 선택에 따른 분기를 반영합니다. A/B/C별 예상 결과, 인기·믿음 변화, 인물의 반응, 지도할 점과 학습 요소를 미리 볼 수 있습니다. 학생 화면에는 이 미리보기 버튼을 표시하지 않습니다.

화면 반짝임과 클릭·결과 입자 효과는 제거했습니다. 대사 표시 효과와 음악·효과음은 별도로 조절할 수 있습니다. 매직메이커AI는 생성한 **세로 디스플레이 키오스크** 안에 실제 화면 내용을 표시합니다. 키오스크 화면 페이지도 교사의 진행 위치와 동기화됩니다.

## 개인 PNG 리포트

8라운드 후 **나의 배움 · PNG**에서 배운 점을 하나 이상 고르고 **개인 리포트 PNG 다운로드**를 누릅니다. 선택한 배움은 해당 수업·학생 기기에 저장합니다.

- 매 라운드의 내 선택과 당시의 예상 결과·점수 변화
- 실제 학급 확정 선택, 실제 결과·누적 인기와 믿음 변화
- 라운드별 배울 점, 내가 고른 학습 요소, 최종 엔딩과 실천 약속

개인 선택과 실제 학급 결과를 구분하며, 제출하지 않은 라운드는 **제출 기록 없음**으로 표시합니다. 긴 문장은 실제 글꼴로 길이를 측정한 뒤 이미지 높이를 정해 잘리지 않게 저장합니다. 태블릿에서 자동 다운로드 대신 이미지 저장이 필요하면 함께 열린 리포트 이미지를 길게 눌러 저장할 수 있습니다.

같은 기기·브라우저·웹 주소로 다시 입장하면 기존 선택을 이어받습니다. 다른 기기·시크릿 창·삭제된 브라우저 저장소에서는 새 참가자로 입장하며, 이전 기기의 선택을 자동 복구하지는 않습니다.

## 실시간 배포에 필요한 작업

**이 변경은 GitHub 소스 및 로컬 검증 결과입니다. 운영 Firebase Hosting과 Realtime Database에는 아직 배포하지 않았습니다.** 기존 v3 주소가 자동으로 v4로 바뀌지는 않습니다.

1. 기존 Firebase 전체 규칙을 읽고 `database.harm-v4.rules.json`의 `rules.roomsHarmV4`만 병합합니다. 이 파일만으로 전체 서버 규칙을 덮어쓰면 안 됩니다.
2. 병합한 규칙을 기존 게임 Firebase 프로젝트의 해당 Realtime Database에 적용합니다.
3. 웹 호스팅의 `harm/harm_v4/index.html` 경로에 빌드 결과를 배포합니다. 이후 해당 웹 주소에서 실제 교사·학생 기기로 확인합니다.

내보낸 기존 규칙 파일이 있으면 다음 명령으로 다른 분기를 유지한 병합 파일을 만듭니다.

```text
node harm/harm_v4/source/merge-rules.cjs existing-rules.json merged-rules.json
```

방은 `roomsHarmV4`, 시나리오는 `harm-2026-11-05-v4`를 사용합니다. 기존 `roomsHarmV3`는 유지합니다. 서버 규칙에는 교사 소유권, 자기 투표만 쓰기·읽기, 수동 마감 후 쓰기 거부, 새 단서 단계와 대사 위치, 시간 제한 없는 투표, 변경 불가능한 확정 선택, 엔딩 검증이 포함됩니다.

## 빌드와 점검

저장소 루트에서 실행합니다. Python 3은 기본 라이브러리만 필요하며, 브라우저 검사에는 Node.js, Playwright와 Edge가 필요합니다.

```text
python harm/harm_v4/source/build.py
python harm/harm_v4/source/build_rules.py
node harm/harm_v4/source/verify-rules.cjs
node harm/harm_v4/source/verify-v4.cjs
node harm/harm_v4/source/verify-classroom-v4.cjs
```

| 점검 | 범위 |
|---|---|
| 시나리오·엔딩 | 6,561가지 학급 선택과 서버 엔딩 검증식 |
| 수동 진행 | 모든 단계·대사, 미응답, 재투표, 동률, 오래된 투표, 결과 중복 방지 |
| 화면 | 1180×820, 1024×768, 1280×800, 1366×768, 1280×650, 768×1024에서 교사·학생·미리보기 576개 라운드 화면 |
| QR·리포트 | QR 생성, 링크 일치, 선택별 해설, 실제 PNG 다운로드와 이미지 확인 |
| 여러 기기 흐름 | 분리된 브라우저의 교사 1·학생 2, 8라운드, 교사·학생 새로고침, 투표·배움 복구 |

여러 기기 검사는 Firebase SDK 전송 부분을 대체한 테스트 연결입니다. 규칙 검사는 표현식 검사이며 Firebase 에뮬레이터·운영 서버에서의 검증은 아닙니다. 실제 iPadOS·Android 기기 검사는 수행하지 않았습니다. 작은 휴대폰·확대 글꼴에서는 내용 접근을 위해 스크롤을 허용합니다. 긴 교사 해설·리포트 미리보기는 팝업 안에서 스크롤됩니다.

검증 기록은 `verification-*.json`, 빌드 해시는 `build-info.json`, 캡처와 샘플 PNG는 Git에서 제외한 `qa/`에 있습니다. QR 라이브러리는 [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)의 MIT 라이선스 코드를 내장합니다. 공통 팩과 기존 사용자 제공 음악은 v3와 동일하게 유지합니다.
