# 급식 메뉴 AI ‘냠냠봇’ v2

**[냠냠봇 v2 공개 게임 바로 플레이](https://ethicity-nyamnyam-v2.hollowcorn.chatgpt.site)** · [실행 파일](index.html) · [저장소 첫 README](../README.md)

설치나 로그인 없이 주소를 가진 누구나 플레이할 수 있습니다. PC·태블릿·휴대폰에서 위 링크를 열어 주세요. GitHub의 실행 파일 링크는 소스 보기용입니다.

확정한 [시나리오 수정용 통합본 2](https://docs.google.com/document/d/1f8AZDLyku36wqywkEHnFHbyU8zk4091lGATZP52Zzdo)의 질문 ①~⑨ 결정을 반영한 버전입니다. 기존 게임은 /data/, 새 버전은 /v2/입니다. Git 브랜치는 data입니다.

## 실행과 자산

공개 게임은 Sites에 배포되어 있으며 로컬 서버를 켤 필요가 없습니다. 아래 명령은 소스를 내려받아 수정하거나 오프라인으로 실행하려는 개발자를 위한 방법입니다.

저장소 루트에서 정적 서버를 실행한 뒤 /v2/에 접속하거나 v2/index.html을 직접 엽니다. 공통 폴더 ../shared/ethicity-elementary-common-v1/가 함께 있어야 합니다. 실행 중 외부 API·CDN·AI 서비스는 필요 없습니다.

Python이 설치되어 있다면 저장소 루트에서 다음 명령을 실행한 뒤 [로컬 v2 미리보기](http://127.0.0.1:8765/v2/)를 누르세요.

```sh
python -m http.server 8765 --bind 127.0.0.1
```

common.css, manifest.js, common.js와 공식 캐릭터 7명(robot, teacher, jiho, saebom, haneul, daon, onyu)을 사용합니다. 사서는 등장하지 않습니다. 기존 /data/와 공통 패키지 91개 파일은 수정하지 않았습니다. 디지털 설문·응답·접근 권한은 실제 텍스트와 공통 UI로 표현합니다. food.js는 그림 응답 활동에만 사용하는 작은 SVG 음식 그림이며 공통 캐릭터·소품·아이콘을 대체하지 않습니다.

## 흐름

START → INTRO → RULE → 장면 0~5 → RESULT → COMPLETE.
장면 4는 방법 2개 선택 → 선택 순서대로 후속 활동 → 선택형 추가 점검 → 교사 안전 확인 → 고친 급식안 순서입니다.

- 디지털 응답 수는 원래 설문 17개(12+2+2+1)입니다. 재방문·그림 응답·질문 보완 시 중복 집계하지 않습니다.
- 장난 중복 응답은 월~수 짜장면, 가짜 응답은 금요일 땅콩 버터 피자에 각각 영향을 줍니다. 목요일 땅콩 소스 치킨은 모든 첫 급식표에 남습니다.
- 알레르기와 매운 정도는 각각 독립된 개선 방법입니다. 질문 추가 후 응답 확인까지 완료해야 상태가 바뀝니다.
- 추가 수집, 그림 응답, 교사 확인 활동도 실행 결과를 반영합니다. 추가 점검에서는 아직 해결하지 않은 항목만 나타납니다.
- 처음 상태(first)는 성찰 기록으로 고정하고, 현재 상태는 실제 개선 완료 시 갱신합니다. 선택만 눌러서는 해결로 처리하지 않습니다.
- 결과는 현재 상태 기준입니다. 모두 해결하면 ‘모두가 맛있는 급식’, 중복·가짜가 남거나 수집과 질문이 함께 부족하면 ‘다시 짜 볼 급식’, 그 외 미해결 항목은 ‘조금 더 살펴볼 급식’입니다.
- 모든 경로에서 위험한 메뉴는 교사가 막습니다. 미완료 결과의 개선 메뉴는 ‘검토 중인 안’으로 표시합니다.
- 결과에 발견 3개, 낱말 카드 5장, 약속 3개 선택과 하나 고쳐 쓰기를 제공합니다.

## 파일

- scenario.js: Google Docs 항목 ID별 원문. 이후 문구 수정의 기준입니다.
- story.js: 캐릭터·활동 데이터, 처음/현재 상태, 급식표와 결과 계산.
- game.js: 대화, 타자 효과, 선택, 후속 활동, 추가 점검, 통합 이벤트.
- styles.css: .game-data 아래의 게임 전용 화면. 공통 UI 토큰을 재정의하지 않습니다.
- food.js: 그림 응답 활동의 음식 그림.
- assets/pixel-adventure.mp3: 사용자가 제공한 `Pixel Adventure (1).mp3` 원본 BGM.
- assets/cursor-*.svg: 게임 화면의 1.5배 커서(24px 기준 36px). 공통 자산은 변경하지 않습니다.

## 대화와 소리 설정

- 설정의 ‘대화 표시’에서 ‘한 글자씩 나타나기 / 한 번에 나타나기’를 선택합니다. 움직임 줄이기를 켜면 즉시 표시합니다.
- 대화창에는 현재 말풍선 하나만 보입니다. 다음 대사로 바뀌면 이전 말풍선은 사라지고, 장면·활동 전환 시 이전 자료도 비웁니다. 현재 활동의 응답 자료와 급식표는 선택하는 동안 함께 표시합니다.
- 배경음악은 탐험 시작 버튼을 누른 뒤 반복 재생합니다. 기본 볼륨은 25%이며 설정에서 끄거나 볼륨을 바꿀 수 있습니다. 효과음은 별도로 켭니다.
- 다른 탭으로 이동하면 음악을 멈추고 돌아오면 이어 재생합니다. 처음 화면으로 돌아가면 음악도 초기화합니다. 설정은 저장하지 않습니다.
- 마우스 환경에서 화살표·선택·글쓰기 커서를 36px로 표시합니다. 터치 조작은 그대로 사용할 수 있습니다.

## 접근성과 개인정보

실제 button, Tab/Enter/Space, 숫자 1~4 단축키, 선택 상태 aria-pressed, 스크린 리더 알림을 제공합니다. 5번째 이후 선택지는 터치·Tab으로 접근합니다. 7개 방법 목록은 스크롤하고 확정 버튼은 고정합니다. 타자 표시 중 한 번 누르면 문장이 완성되고 다음에 누르면 넘어갑니다. 즉시 표시 설정과 prefers-reduced-motion도 지원합니다.

디지털 설문은 가상의 연출이며 실제 이름·건강정보·비밀번호를 입력받지 않습니다. 성찰 입력과 약속 수정은 메모리에서만 사용합니다. 저장소·쿠키·분석 도구·API 전송은 없고 입력은 HTML로 실행되지 않습니다.

## 통합 이벤트

게임 ID는 동일 시리즈 통합을 위해 data를 유지합니다. v2는 URL로 구분합니다. 각 게임 iframe은 부모 페이지에서 event.source로 구별해야 합니다.

- ethicity:ready: { gameId: 'data' }
- ethicity:progress: { gameId: 'data', current: 1..6, total: 6 }
- ethicity:complete: { gameId: 'data', result: { completed: true } }, 완료 시 한 번
- ethicity:exit: { gameId: 'data' }, 다른 탐험으로 돌아가기 요청

실제 이벤트에는 type 필드도 포함합니다. 입력 내용이나 개인 정보는 포함하지 않습니다.

### 로컬 검사

node v2/tests/model.cjs
node v2/tests/browser.cjs
node v2/tests/effects.cjs

모델 검사는 4,096개 상태 조합의 독립적인 메뉴 영향, 질문 분리, 중복 없는 응답 수, 처음 기록 보존, 개선 후 결과를 확인합니다.

브라우저 검사는 Playwright와 설치된 Edge를 사용합니다. 개발 환경의 NODE_PATH로 Playwright를 제공하거나 로컬에 설치합니다. ETHICITY_EDGE_PATH로 Edge 경로를 지정할 수 있습니다. 게임 실행에는 이 도구가 필요 없습니다. 테스트 결과와 캡처는 Git에서 제외한 tests/artifacts/에 생성됩니다.

effects.cjs는 대화 표시 선택, 현재 말풍선만 표시, 장면 초기화, 커서, 시작 전 음악 정지, BGM 재생·반복·음소거·볼륨, 움직임 줄이기와 처음으로 돌아가기를 확인합니다. ETHICITY_TEST_URL을 지정하면 공개 주소에서도 같은 검사를 실행합니다.

데스크톱 1280×900, 태블릿 760×900, 모바일 430×740 및 430×932에서 네 경로를 완료하며, 수정 후 결과·미완료 결과·키보드·터치·타자 효과·동작 줄이기·자유 입력 이스케이프·통합 이벤트·외부 요청·콘솔 오류를 확인합니다. 실제 학생의 이용 시간과 실제 휴대폰 사용감은 수업 환경에서 확인해야 합니다. 기본 목표는 8~10분이며 추가 점검을 많이 하면 더 길어질 수 있습니다.
