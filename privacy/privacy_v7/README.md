# 프라이버시 보호 privacy_v7

2026년 11월 8일 첫 화면 개선판입니다. GitHub `privacy` 브랜치의 **privacy/privacy_v7** 폴더에 별도로 보관합니다. 기존 **v6·v5 및 이전 버전의 파일·웹 주소는 변경하지 않습니다.**

| 용도 | 실행 주소 |
|---|---|
| 교사: 수업 만들기·실시간 진행·리포트 | [privacy_v7 교사 컨트롤타워](https://ethicity-privacy-20261011.web.app/privacy/privacy_v7/teacher.html) |
| 혼자 탐험·수업 전 미리보기 | [privacy_v7 게임](https://ethicity-privacy-20261011.web.app/privacy/privacy_v7/index.html?mode=solo) |
| 이전 v5 | [기존 v5 게임](https://ethicity-privacy-20261011.web.app/v5/) |

**실시간 수업의 학생은 선생님이 만든 QR이나 수업별 입장 링크를 사용합니다.** 기본 주소는 교사 시작 화면입니다. **수업 미리보기**는 새 탭에서 혼자 탐험하며 교사 집계에 연결되지 않습니다.

## 교사: 수업을 시작하는 방법

1. 교사 컨트롤타워를 열고 **새 수업 만들기**를 누릅니다. 회원가입·Google 로그인은 필요하지 않습니다.
2. 나타난 **QR 코드**를 학생에게 보여 주거나 **입장 링크 복사**로 수업 링크를 공유합니다. **QR 크게 보기**로 확대할 수 있습니다.
3. 학생이 입장을 마치면 닉네임이 실시간으로 표시됩니다. 명단은 입장 기록이며, 창을 닫은 학생도 남습니다.
4. **1라운드 시작 →**을 누릅니다. 교사 화면에는 현재 상황·장면과 네 선택의 개인정보 보호/이용 편리성 점수 및 이유가 표시됩니다.
5. **선택 집계**에서 제출 인원을 확인하고 **선택 결과 공개**를 누릅니다. 공개된 뒤 학생 화면에도 점수와 설명이 나타납니다.
6. 선택 이유를 함께 이야기한 후 **다음 라운드 →**로 진행합니다. 마지막에는 **수업 마무리**를 누릅니다. 놓친 사례가 있는 학생은 남은 사례를 이어서 마칩니다.

**학생과 함께 보는 화면**을 누르면 응답 중인 라운드의 점수 판정 설명을 숨깁니다. 교사 전용 집계·리포트를 화면 공유할 때는 학생별 기록이 보인다는 점을 고려합니다. **선택 집계 크게 보기 ↗ / 입장 명단 크게 보기 ↗**는 별도 창으로 열며, 팝업이 차단되면 현재 화면 확대를 이용합니다.

과거 수업 목록은 표시하지 않습니다. **수업을 만든 같은 브라우저에서 새로고침하면 현재 수업을 복원**합니다. 비공개 창을 닫거나 사이트 저장정보를 지우면 수업 열쇠가 사라집니다. 수업 후 필요한 리포트를 먼저 저장합니다.

## 학생: 수업에 입장하는 방법

1. 선생님의 QR 코드를 찍거나 입장 링크를 엽니다.
2. **A버전 탐험가 / B버전 탐험가**를 고르고 한글 1~5자 닉네임을 씁니다. 실제 이름은 쓰지 않습니다. 부적절한 표현은 제한하지만 모든 변형을 감지하는 것은 아닙니다.
3. **이야기 시작하기 →**를 누릅니다. 가상 친구는 **새봄**으로 통일되어 있습니다.
4. 도입 대화를 읽고 **수업에 입장하기 →**까지 눌러야 교사 명단에 나타납니다.
5. 사례 → AI 화면 관찰 → 위험 신호 확인 → 보호 방법 선택 → 결과 순서로 진행합니다. 글자가 나오는 중에는 화면·말풍선을 누르거나 Enter/Space로 모두 펼칩니다.

신호는 여러 개 고를 수 있습니다. **선택한 신호 확인** 후 잘못 짚은 안전한 항목의 설명을 먼저 보여 줍니다. **다시 골라 보기**로 바꿔도 감점하지 않습니다. 처음 확인한 신호와 최종 신호·확인 횟수는 리포트에 남습니다.

## 두 점수의 의미

각 선택에는 독립적인 두 지표를 0~2점으로 정했습니다. 점수는 `scenario.json`에 설명과 함께 모여 있습니다.

| 지표 | 무엇을 뜻하나요? |
|---|---|
| 개인정보 보호 | 꼭 필요한 정보만 주기, 다른 사람의 정보·계정 보호, 삭제 확인의 정도 |
| 이용 편리성 | 그 선택에서 기능을 바로 이용할 수 있는지, 확인·설정에 필요한 단계와 수고 |

두 점수는 **합산하거나 순위를 매기지 않습니다.** 편리성 2점이 더 옳은 선택이라는 뜻도 아닙니다. 각 라운드의 안전한 선택 두 가지는 기존과 동일하게 개인정보 보호 2점입니다. 위험 신호를 다시 고른 횟수는 점수에 반영하지 않습니다.

학생 막대그래프는 결과가 공개된 라운드만 계산합니다. 예를 들어 3개 결과를 봤다면 각 지표를 `/6점`으로 표시하고, 완료 후 각각 100점 기준으로 환산합니다. 기존 A/B/C 엔딩 기준은 개인정보 보호 점수 13점 이상 / 8점 이상 / 그 미만으로 유지합니다. 어떤 엔딩이든 8개 선택과 엔딩에 도달하면 완료입니다.

## 개인 리포트 저장

- 학생: 엔딩의 **나의 리포트 보기** → **인쇄 / PDF 저장** 또는 **리포트 파일 저장**.
- 교사: **학생 리포트** 탭 → 학생 한 명의 **리포트 보기**, **전체 리포트**, **CSV 저장**.
- 리포트: 닉네임·A/B 탐험가, 라운드별 선택 문장, 처음/최종 위험 신호, 확인 횟수, 두 점수와 이유, 생길 수 있는 일, 다음 보호 방법, 학습 요소 ①~⑤, 손으로 적을 성찰 줄.
- HTML 파일은 따로 열어 인쇄할 수 있습니다. PDF는 브라우저 인쇄창에서 **PDF로 저장**을 선택합니다. CSV는 엑셀 등에서 열 수 있습니다.
- 교사가 **저장한 뒤 수업 기록 삭제**를 선택하면 해당 수업의 서버 기록과 입장 링크가 삭제됩니다. 자동으로 삭제하지 않습니다. 학생은 자기 기록만, 교사는 자신이 만든 수업의 기록만 읽을 수 있습니다.

학습 요소는 중간 선택지·결과에는 표시하지 않고, **마지막 배운 점 화면과 리포트에서 모아** 보여 줍니다. 결과의 가상 상황은 생길 수 있는 예시이며 실제 피해 확률이나 확정된 결과가 아닙니다.

## 화면과 자료

8라운드의 순서는 가입 → 계정 보호 → 친구 관계 대화 상담 → 사진 보정 → 새 동의 → 사진 공개 → 공용 태블릿 → 계정 정리입니다. 친구와 플레이어의 말풍선은 이름·방향·색으로 구별합니다. 로봇은 함께 생각하자고 안내합니다.

공통 팩의 캐릭터·배경·props·아이콘·효과·효과음·글꼴·UI 파일 91개는 원본 그대로입니다. 기존 장면 삽화 8장과 사용자 제공 Pixel Adventure 음악을 재사용합니다. 새로 만든 것은 **헬피AI 관찰 자료를 담는 스마트폰 프레임**이며, 글과 버튼은 이미지 안의 HTML로 표시합니다. 공용 태블릿 사례는 태블릿 형태로 보여 줍니다.

태블릿 기본 글자 크기에서 1024×768·768×1024·1280×800·800×1280 배치를 제공합니다. 긴 대화·관찰 자료·설명은 페이지로 나눕니다. 회전은 진행 상태를 초기화하지 않습니다. 모바일은 세로 배치와 필요한 세로 스크롤을 사용합니다. 확대 글자·브라우저 확대 및 리포트 창은 접근성을 위해 스크롤을 허용합니다.

## 파일 구성과 수정

| 파일·폴더 | 용도 |
|---|---|
| `index.html`, `teacher.html` | 게임 시작 / 교사 화면 진입 |
| `scenario.json` | 대사·선택·점수·판정 이유·가상 결과·학습 요소 |
| `source/classroom.js`, `source/classroom.css` | 수업 화면·페이지 나누기·기기별 배치 |
| `source/reports.js` | 두 지표·개인 리포트·CSV |
| `source/live.js` | Firebase 실시간 수업 |
| `source/case-data.js`, `source/case-screens.js` | 가상 AI 화면의 읽을 수 있는 내용 |
| `common/` | 수정하지 않은 윤리시티 공통 팩 |
| `assets/devices/helpy-phone.png` | 새 스마트폰 프레임 |
| `assets/scenes/`, `assets/audio/` | 기존 삽화와 배경음악 |
| `vendor/qrcode.js` | 로컬 QR 생성기·MIT 라이선스 |
| `database.v7.rules.json` | v7 전용 수업 데이터 보안 규칙 |

문장을 수정한 뒤 `python source/build.py`를 실행합니다. `index.html`만 복사하지 말고 **privacy_v7 폴더 전체**를 함께 배포합니다. 파일로 여는 혼자 탐험은 인터넷 없이 진행하며, 실시간 수업만 Firebase에 연결합니다.

허브 저장 형식은 `ethicity.player`와 `ethicity.result.privacy`를 유지합니다. v7의 수업과 임시 진행 상태는 v6·v5와 분리합니다. 수업 데이터 경로는 `roomsPrivacyV7Classroom20261108`입니다.

검사: `node tests/verify.cjs`, `node tests/verify-revision.cjs`, `node tests/verify-classroom.cjs`, `python tests/verify_assets.py`. 65,536개 선택 경로의 엔딩·서버 판정 일치, 저장 차단 환경, 보고서 문자 처리, 두 점수 공개 시점, 원본 공통 자산을 검사합니다.

## v7 첫 화면

- 레퍼런스와 같은 왼쪽 안내 패널 / 오른쪽 AI 연구실과 진행 안내 구성입니다. 공통 UI·캐릭터·배경은 원본 그대로 사용합니다.
- **새 수업 만들기 / 연결 다시 확인 / 수업 미리보기**를 제공합니다. 연결되지 않으면 수업 만들기 버튼을 비활성화합니다.
- 상단 **화면·소리**에서 타이핑, 효과음, 배경음악·음량, 전체 화면을 조절합니다.
- 교사가 **처음으로**를 눌러도 진행 중인 수업은 삭제하지 않으며 돌아가기 버튼을 제공합니다.
- v6의 8라운드 시나리오, 점수, QR 초대, 실시간 명단, 개인 HTML/PDF/CSV 리포트는 유지합니다.
- 허브의 프라이버시 카드는 이 버전의 교사 컨트롤타워를 엽니다.
