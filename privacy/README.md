# 프라이버시 보호 — 친구의 정보 발자국

초등학교 5~6학년용 AI 윤리 교육 게임이에요. 헬스케어 AI와 사진 보정 AI 사례를 통해 개인정보를 **모으기 → 저장·관리 → 쓰기·주기 → 지우기**의 네 단계에서 보호하는 방법을 배워요.

## 바로 실행하기

- **[교사 컨트롤타워 열기](https://ethicity-privacy-20261011.web.app/privacy/?mode=teacher)**
- **[학생용 게임·혼자 탐험 열기](https://ethicity-privacy-20261011.web.app/privacy/)**

실시간 수업에 참여하는 학생에게는 **교사 화면에서 만든 학생 입장 링크**를 전달해 주세요. 위의 일반 게임 주소로 접속하면 혼자 탐험하는 화면이 열려요.

## 교사용 진행 방법

1. 교사 컨트롤타워에서 **Google 계정으로 교사 로그인**을 눌러요. 기존에 이 게임의 교사로 등록한 계정을 사용해요.
2. **새 수업 만들기**를 눌러요.
3. **학생 입장 링크 복사**를 눌러 학생들에게 주소를 공유해요.
4. 학생이 모이면 **새 입장 마감하기**, **1라운드 시작하기**를 눌러요.
5. 학생이 선택하면 교사 화면의 응답 인원과 선택별 인원이 갱신돼요.
6. **응답 마감 · 결과 공개**를 누르고 선택 이유를 함께 이야기해요. 이어서 **다음 라운드 열기 →**를 눌러요.
7. 8라운드의 결과를 공개한 뒤 **수업 마무리 · 남은 사례 열기**를 눌러요.
8. 필요한 경우 **기록 CSV 내려받기**로 수업 기록을 저장해요.

응답을 받는 동안에는 선택 집계를 학생에게 보여 주지 않도록 안내해요. 다른 선생님이 교사 기능을 사용하려면 Firebase의 교사 권한 등록이 필요해요. GitHub 저장소 접근 권한과 게임의 교사 권한은 별개예요.

## 학생용 진행 방법

1. 선생님이 보내 준 **학생 입장 링크**를 열어요. 학생은 Google 계정으로 로그인할 필요가 없어요.
2. 캐릭터를 고르고, 내 닉네임과 이야기 속 친구의 가상 별명을 정해요. 두 별명 모두 한글 1~5자예요.
3. 선생님이 라운드를 열면 **사례와 그림 → AI 화면 관찰 → 수상한 부분 선택 → 보호 방법 선택 → 결과** 순서로 진행해요.
4. 글자가 나오는 중에 말풍선이나 화면을 클릭하면 현재 글이 한 번에 나타나요.
5. 선택을 제출한 뒤 교사의 결과 공개와 다음 라운드를 기다려요.
6. 여덟 사례를 마치면 엔딩과 배운 점 한 줄 카드를 확인해요.

교사 집계에는 닉네임 대신 임시 참여번호가 표시돼요. 실제 이름·학교·연락처를 입력하지 않아요.

## 혼자 실행하기

일반 게임 주소에서 혼자 탐험할 수 있어요. 이 폴더의 `index.html`을 내려받아 브라우저로 열어도 혼자 탐험이 가능해요. 그림과 나눔스퀘어라운드 글꼴은 HTML 안에 들어 있어요.

실시간 수업은 인터넷 연결과 위의 배포된 게임 주소를 사용해요. GitHub에서 파일 내용을 보는 화면은 게임 실행 화면이 아니에요.

## 파일 구성

- `index.html`: HTML·CSS·JavaScript·그림·글꼴을 포함한 게임 한 파일
- `README.md`: 교사·학생 사용 안내
- `NanumSquareRound-LICENSE.txt`: 포함된 글꼴의 이용 조건

게임은 8라운드이며, 라운드마다 보호 방법 선택지가 4개 있어요. 시나리오와 선택지는 HTML의 `id="game-data"` 부분에 모아 두었어요.

## 통합 허브 연결

공통 캐릭터는 아래 형식으로 저장해요.

```text
localStorage 키: ethicity.player
{"character":"char_03","nickname":"별고래"}
```

완료하면 아래 형식으로 기록해요.

```text
localStorage 키: ethicity.result.privacy
{"game":"privacy","completed":true,"ending":"B","card":"정보가 왜 필요한지 확인하고 신중하게 제공해요."}
```

친구 별명은 이 편 전용 `ethicity.privacy.friendName` 키에 따로 저장해요. 현재 캐릭터 ID `char_03`, `char_04`는 팀 합의 전의 임시 값이에요.

허브와 다른 게임이 같은 저장값을 읽으려면 같은 도메인·프로토콜·포트에서 실행해야 해요. GitHub 주소와 Firebase 주소 사이에는 브라우저 저장값이 자동으로 공유되지 않아요. 최종 허브에 합칠 때는 같은 사이트의 `/privacy/` 경로로 배치해요.
