# 윤리시티 공공성 게임 — 사라진 우리들의 공원 v0.4

## v0.4 사운드 재생 개선

- 이전 Web Audio 실시간 합성 방식이 일부 브라우저에서 들리지 않는 문제에 대응해 **실제 MP3 음악·효과음 8개**를 `assets/audio/`에 포함했습니다.
- HTML 오디오 파일 재생 방식을 사용해 파일을 더블클릭하여 실행하는 Chrome/Edge 환경에서도 재생되도록 구성했습니다.
- 메인 화면 오른쪽 위 `🔔 소리 테스트` 버튼으로 게임 시작 전에 소리를 확인할 수 있습니다.
- 배경음악은 게임 시작 후 반복 재생되며, 정지·음소거·브라우저 탭 전환 시 재생 상태를 관리합니다.
- 브라우저의 재생 차단이나 파일 누락을 감지하면 소리 버튼 아래에 안내가 표시됩니다.
- `generate_audio.py`로 게임의 오리지널 음악과 효과음을 다시 생성할 수 있습니다(추가 설치 없이 실행하려면 포함된 MP3 파일을 그대로 사용하세요).

## v0.3 변경 사항

- 기존 이미지·움직임·포털·스페이스 수집을 유지하면서 오리지널 픽셀풍 배경음악을 추가했습니다.
- 대화 시작, 증거 수집, 포털 전환, 시설 선택, AI 판단 성공·실패, 공원 개장, 엔딩에 효과음을 추가했습니다.
- 오른쪽 위 `🔊 사운드 켜짐 / 🔇 사운드 꺼짐` 버튼으로 음악과 효과음을 함께 켜고 끌 수 있습니다. 선택은 이 브라우저에 저장됩니다.
- 소리는 브라우저의 자동 재생 제한을 준수하여 `새 게임 시작` 또는 `이어서 하기`를 누른 뒤 시작합니다.
- 별도 음악 저작물을 사용하지 않고 Web Audio로 직접 생성한 오리지널 멜로디와 소리를 재생합니다.

## v0.2 변경 사항

- 주민 근처로 가면 대화 팝업이 자동으로 나타납니다(기존 유지).
- 대화 팝업에서 **스페이스바**를 한 번 누르면 단서가 수집되고 창이 닫힙니다.
- 수집 버튼을 마우스로 클릭하는 방법도 유지합니다.
- 스페이스바를 길게 눌렀을 때 중복 수집되거나 화면이 스크롤되지 않도록 처리했습니다.

초등학교 5~6학년용 AI 윤리·공공성 탐험형 게임 프로토타입. 기존 마을버스 게임과는 별도의 새 스토리입니다.

## 실행

ZIP을 통째로 압축 해제하고 `index.html`을 Chrome 또는 Edge에서 엽니다. 별도 설치나 웹서버가 필요 없습니다. `assets/`, `style.css`, `game.js`를 같은 폴더 구조로 유지해야 합니다.

## 플레이 구조

1. 메인 화면: 별명과 캐릭터 선택. 저장된 기록이 있어도 첫 화면부터 시작하며, 별도로 이어하기를 누를 수 있습니다.
2. 개장식: 마을 담당자·파크봇·온유의 프롤로그 4장면.
3. 탐험: 넓은 별빛공원 지도에서 주민 4명에게 접근해 단서를 수집.
4. 포털: 공원 위쪽 AI 관리실 포털에 닿으면 관리실로 전환. 관리실 아래쪽 포털로 공원으로 복귀.
5. 데이터 분석: AI가 고려하지 않은 공공성 기준 3개를 찾아 수정.
6. 공원 설계: 제한된 10칸 예산 안에서 시설 6종 설치·해제. 기본 접근 경로는 필수.
7. 시범 개장: 선택한 시설에 따라 주민 반응 확인 및 재설계.
8. 성찰: 공원 운영 원칙 선택 및 탐구 기록 텍스트 다운로드.

## 조작

- **이동:** 방향키 / WASD, 화면 아래 방향 버튼(터치·마우스), 지도 클릭 시 목적지까지 자동 걷기.
- **카메라:** 아바타를 따라 부드럽게 이동하는 추적형 카메라. 지도는 가로·세로로 스크롤됩니다.
- **대화:** 주민 또는 파크봇에게 다가가면 자동으로 뜹니다. `E` 또는 `Enter`도 지원합니다.
- **단서 수집:** 주민의 대화창이 열렸을 때 `Space`를 누르거나 `단서 수집` 버튼을 클릭합니다.
- **포털:** 직접 진입 시 자동 맵 전환. 재진입 지연 및 생성 위치를 조정해 즉시 되돌아가는 현상을 방지합니다.
- **팝업:** 한 번 닫으면 같은 주민에게서 멀어졌다가 다시 접근해야 자동으로 재등장합니다.

## 화면·자료

- 새로 생성한 공원 표지와 넓은 공원 맵, 기존 윤리시티 공통 AI 실습실 배경.
- 기존 하늘·지호·새봄 픽셀 캐릭터 및 새로 만든 마을 담당자·파크봇·온유·정순 할머니·하린 이미지.
- Galmuri11 픽셀 글꼴, 반응형 레이아웃, 별도의 스크롤 대화 모달.
- 이미지와 문구는 별도 파일로 유지되어 수정하기 쉽습니다.

## 확인 사항과 한계

- 노선/예산/이용 정보는 모두 **학습을 위한 가상 사례**입니다.
- 공원 설계 단계는 아이콘 기반 시설 배치 선택이며 자유로운 타일 드래그 건설은 후속 버전에서 구현할 수 있습니다.
- 캐릭터 이동에는 주요 건물과 분수대의 간단한 충돌 영역을 적용했습니다. 모든 배경 장식의 충돌을 완전하게 재현한 것은 아닙니다.
- JS 구문, 파일 경로, 압축 무결성 검사를 수행합니다. 실제 Chrome·Edge 브라우저에서 모든 화면 크기와 기기 조작의 전수 테스트는 추가로 필요합니다.
- 학생 실명 입력 금지. 진행 기록은 현재 브라우저 로컬 저장소에만 남습니다.

## 파일 구성

- `index.html` — 화면 구성
- `style.css` — 게임 스타일·반응형 배치
- `game.js` — 상태·캐릭터·포털·카메라·게임 흐름
- `audio.js` — 배경음악·효과음·음소거 제어
- `assets/` — 픽셀 아트 리소스 및 글꼴
