# 공공성 피드백 수정본 v0.6

교사 피드백 PDF 3~4쪽과 사용자가 선택한 방향을 반영했습니다.
기존 publicness는 유지하고 publicness-preview만 수정합니다.

## 학습 흐름

주민 조사 → 같은 5개 기준으로 AI 원래 중요도와 비교 → 중요도 배분 → 학생 직접 설계 → 주민 반응과 AI 평가 확인 → 재설계 → 운영 원칙과 남은 과제 정리.

- AI가 시설을 자동 선택하거나 학생 설계를 덮어쓰지 않습니다.
- 연결길 3칸은 필수, 남은 예산은 7칸입니다. 전체 시설에는 14칸이 필요해 모두 만족하는 정답 설계는 없습니다.
- 주민 4명과 저녁 산책 주민의 필요를 먼저 표시하고 AI 총점은 접힌 상세 설명에 둡니다.
- 처음의 동일한 중요도는 정답이 아닌 시작 예시입니다. 최대 중요도가 같으면 모두 표시합니다.
- 최초 중요도 4/1/1/1/3은 비교를 위해 다섯 항목으로 정리한 가상 설정입니다.
- 운영 효율성은 가상 이용 편익/비용으로 계산합니다. 예산 미사용 자체에 점수를 주지 않습니다. 모든 계수는 상세 계산표에 공개합니다.
- 시범 개장마다 시설·중요도·계산 결과를 복사해 저장하고 최근 두 설계의 시설과 미해결 필요를 비교합니다. 중요도만 바꾸어도 시설은 유지됩니다.
- 마무리와 내려받기 기록에 남은 필요를 포함합니다.
- 생각해 보기 글자를 키웁니다. 기존 방향별 걷기, 가속·감속, 포털 전환, 돌담 충돌은 유지합니다.
- v0.6 전용 저장 키를 사용해 이전 버전 기록을 보존합니다.

## 실행과 검사

저장소 루트에서 HTTP 서버를 실행하고 /publicness-preview/를 여세요.
인접한 publicness/assets가 필요합니다.

`node publicness-preview/evaluation.test.cjs`

64개 시설 조합 × 3개 중요도, 빈 공원 점수, 동일 비용의 효율 비교, 정원·야간 접근 의존성을 검사합니다.
