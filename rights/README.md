# 윤리시티 인권보장 게임 — AI의 판결

## v0.7.2 수정 사항
- 떠 있는 캐릭터 이미지가 증거 문서 상자를 덮던 문제를 수정했습니다.
- 대화 내용(왼쪽)과 전신 캐릭터(오른쪽)를 독립된 두 열로 배치합니다.
- 좁은 화면에서는 캐릭터를 대화 내용 위로 이동시켜 겹침을 방지합니다.

## v0.7.1 수정 사항
- 사건 조사 대화창의 어깨 아래가 잘린 반신 초상화 대신 전신 캐릭터 스프라이트를 표시합니다.
- 캐릭터 프레임 크기를 조정해 발끝까지 보이도록 했습니다.
- 기존 픽셀 아트 스타일, 내용, 사건 순서는 유지했습니다.

## v0.7 개선 사항
- 다른 윤리시티 게임의 대화형 사건 도입과 조사 수첩 구조를 참고했습니다.
- 새봄·온유 사건 이야기를 장면별로 넘기는 방식으로 변경했습니다.
- 현재 사건의 수집 자료, 미확인 자료, 판단 기준을 한눈에 보는 조사 수첩을 추가했습니다.
- 사건 이야기를 수첩에서 다시 볼 수 있습니다.
- v0.6의 포털과 NPC 이동 수정 사항, 공통 픽셀 에셋을 유지했습니다.
- 별도 저장 키로 v0.6의 진행 기록을 보존합니다.

## v0.6 수정 사항
- 중앙마당의 AI 실습실 포털까지 키보드와 지도 클릭으로 접근할 수 있도록 이동 제한을 수정했습니다.
- 8개의 사건 조사 지점을 공통 맵의 걷기 가능 구역에 배치했습니다.
- 기존 픽셀 그래픽·사건 내용·초기 화면은 유지했습니다.
- 새 저장 키를 사용하므로 v0.5 진행 기록과 분리됩니다.
- 실행은 `rights/index.html` 하나로 통일하고 전체 폴더 구조를 유지합니다.

초등학교 5~6학년 대상 AI 윤리(인권보장) 탐험형 게임 프로토타입.

- 사건 1: AI 글 탐지기로 인해 새봄이의 발표 기회가 보류된 사건 조사
- 사건 2: 얼굴인식 출입 시스템으로 인해 온유의 도서관 이용이 제한된 사건 조사
- 최종 목표: 학생의 권리에 영향을 미치는 학교 AI를 어떤 조건에서 사용할지 판단

## 폴더 구성
- `index.html` : 실행 파일
- `scenario.json` : 게임 시나리오 데이터
- `source/` : 템플릿, CSS, JS, 빌드 스크립트
- `tests/` : 기본 검증 스크립트
- `../shared/ethicity-elementary-common-v1/` : 팀 공통 에셋

## 시작 화면 이미지 업데이트 (v0.3)
팀 공통 픽셀 스타일을 유지하고 새로 생성된 이미지의 일러스트 영역만 `assets/intro_mystery.webp`로 적용했습니다. 이름 입력과 버튼은 실제 HTML UI를 유지합니다.
