# 인권보장 · 잠깐! 친구의 이야기를 들어줘

초등 5~6학년용 개인 탐험 게임에 교사 컨트롤타워와 실시간 수업 참여를 추가했습니다. 교실의 AI 글 탐지 오해와 도서관의 얼굴인식 오인, 두 가상 사건을 다룹니다. 게임 코드는 `rights`입니다.

## 두 화면

| 대상 | 파일 | 웹 배포 후 경로 | 하는 일 |
|---|---|---|---|
| 교사 | `teacher.html` | `/rights/?mode=teacher` | 수업 생성, 입장 링크, 닉네임 명단, 4라운드 진행·결과 공개, 선택 집계, CSV |
| 학생 | `student.html` 또는 `index.html` | `/rights/` | 아바타·직접 입력 별명, 학교 이동, 단서 조사, 액션 미니게임, 판단·재검토, 엔딩 |
| 수업에 참여하는 학생 | 교사 화면에서 만든 링크 | `/rights/?mode=student&room=...` | 교사의 라운드에 참여하고, 선택·진행·완료 결과를 이 수업에 전달 |

`teacher.html`과 `student.html`은 같은 폴더의 `index.html`로 연결하는 입구입니다. 세 파일을 같은 폴더에 둡니다. 일반 학생 주소로 접속하면 서버 연결 없이 혼자 탐험합니다. 실시간 수업에는 교사가 만든 **수업별 학생 입장 링크**를 사용합니다.

## 현재 배포 상태

이 묶음은 팀 저장소 `heeru-tea/ethicity-games`의 `main` 커밋 `ffd9433`에 있는 `privacy-v3` 구조를 확인해 제작했습니다. 기존 Firebase 프로젝트의 공개 클라이언트 설정을 사용하되, 데이터 경로를 **`rightsRoomsV1`**로 분리했습니다.

**이 파일을 만드는 과정에서 실서비스 Firebase 규칙과 호스팅은 배포하지 않았습니다.** 파일 업로드만으로 실시간 수업 권한이 생기지는 않습니다. 관리자가 아래 서버 규칙을 적용하고 `/rights/` 경로로 게시해야 합니다. 내려받은 파일을 직접 열면 학생의 혼자 탐험과 교사 화면 구성을 확인할 수 있으며, 실시간 연결은 배포한 HTTPS 주소에서 합니다.

## 교사의 수업 진행

1. 교사 화면에서 **수업 서버 연결 → 새 수업 만들기**를 누릅니다.
2. **학생 입장 링크 복사**로 생성한 주소를 학생에게 공유합니다.
3. 학생이 별명과 아바타를 고르고 도입에서 **선생님 수업에 입장**을 누르면 명단에 표시됩니다.
4. **1라운드 시작**을 누릅니다. 학생은 교실에서 단서를 찾고 ‘단서 캐치’를 마친 후 판단합니다.
5. 응답 중에는 집계를 교사용으로 사용합니다. **응답 마감 · 결과 공개** 후 학생의 선택 뒤 이야기가 열립니다.
6. 선택 이유를 이야기하고 다음 라운드를 엽니다. 3~4라운드는 도서관의 ‘확인 타이밍’과 연결됩니다.
7. 마지막 결과를 공개하거나 수업을 마무리하면 학생이 최종 문을 열고 엔딩을 확인합니다.
8. 필요하면 **기록 CSV**를 내려받고, **이 수업 기록 삭제**로 정리합니다.

입장 명단은 입장 기록입니다. 창을 닫은 학생도 남으며, 현재 접속 중이라는 의미는 아닙니다. 같은 별명은 입장 순서로 구별됩니다. 집계는 최초 제출 선택을 기준으로 하고, 이후 재검토는 완료 엔딩에 반영됩니다. 늦은 학생은 교사가 다음 라운드를 열거나 수업을 마친 뒤 이전 사례를 마무리할 수 있습니다.

교사 권한은 수업을 만든 브라우저의 Firebase 익명 인증으로 확인합니다. Google 로그인은 필요하지 않습니다. 같은 기기·브라우저로 다시 접속합니다. 저장이 차단된 브라우저에서는 창을 닫기 전에 필요한 CSV를 받습니다.

## 학생의 조작

- 시작 전에 아바타 2종과 직접 입력한 한글 1~5자 별명을 선택합니다. 실제 이름 대신 가상 별명을 사용합니다.
- 방향키·WASD·화면 방향 버튼으로 움직이고, E·Enter·조사 버튼으로 상호작용합니다. 한글 입력 상태의 물리 E 키도 지원합니다.
- Home 키 또는 중앙 마당 버튼으로 돌아옵니다. 모은 단서는 유지되고 액션 도전은 일시 정지됩니다.
- 글 조각 복원과 기록 비교로 단서를 조사하고, 단서 캐치·확인 타이밍을 완료해 열쇠를 얻습니다.
- 액션 도전에는 시간 제한 없는 모드와 재도전이 있습니다. 액션 속도와 콤보는 인권 판단이나 엔딩 등급에 영향을 주지 않습니다.
- 시작 화면의 **소리 들어보기**, **소리 켜고 탐험 시작**으로 내장 배경음과 효과음을 사용합니다. 각각 끌 수 있습니다.
- 수업 참여 중에는 교사의 결과 공개까지 선택 뒤 이야기가 보류됩니다. 연결이 어려우면 혼자 탐험으로 전환할 수 있고, 그 이후 선택은 교사에게 보내지 않습니다.

## Firebase 규칙 적용

`database.rules.json`은 팀의 `privacy-v3/database.rules.json`을 기준으로 기존 `teachers`, `rooms`, `roomsV2`, `roomsV3`를 그대로 보존하고 `rightsRoomsV1`만 추가한 합본입니다. **실서버의 최신 규칙과 비교·병합한 뒤** 관리자가 적용합니다. 다른 경로의 규칙을 삭제하거나 공개 읽기·쓰기를 허용하지 않습니다.

`firebase.database.json`은 데이터베이스 규칙만 지정합니다. 호스팅을 통째로 덮어쓰는 설정은 포함하지 않았습니다. 프로젝트 관리자 인증이 준비된 경우 저장소 루트에서 다음처럼 데이터베이스 규칙만 적용할 수 있습니다.

```bash
firebase deploy --only database --project ethicity-privacy-20261011 --config rights/firebase.database.json
```

Firebase Authentication의 익명 로그인을 사용합니다. 새 호스팅 도메인을 사용한다면 Firebase의 승인된 도메인 설정도 확인합니다. GitHub 파일 조회 화면은 게임 실행 화면이 아닙니다. 팀의 기존 호스팅 배포 구성에 `rights/` 폴더를 추가합니다.

## 저장·접근 범위

- 공통 플레이어: `ethicity.player` → `{character,nickname}`
- 공통 완료: `ethicity.result.rights` → `{game:"rights",completed:true,ending,card}`
- 실시간 수업: 이 수업의 별명·캐릭터 ID·입장 시각·최초 선택·진행 요약·완료 결과를 서버에 보관합니다.
- 학생은 자기 기록만 읽고 쓸 수 있습니다. 교사는 자신이 만든 수업만 조회·조작합니다.
- 수업별 진행 초안은 해당 기기의 브라우저에 보관합니다. 다른 기기에서 자동으로 이어지는 기능은 아닙니다.
- 인권보장 수업은 프라이버시 게임의 수업 기록을 읽거나 바꾸지 않습니다.

## 검증 범위

`검증결과.json`에 검사 결과를 포함했습니다. 게임의 4개 엔딩, 재검토, 키보드, 별명 입력, 액션 도전, 저장 예외와 교사 화면 렌더링을 검사했습니다. 별도의 Firebase 로컬 서버에서 교사 1명·학생 2명의 입장·실시간 집계·결과 공개·별명 변경·CSV, 응답 시점, 중복 제출, 권한 격리를 확인했습니다.

실제 브라우저·태블릿 렌더링, 실제 스피커 재생, 실서비스에서의 익명 인증 유지·재연결은 아직 확인하지 않았습니다.
